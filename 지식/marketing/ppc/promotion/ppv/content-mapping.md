> 적용대상 **PPV 전용** · 관련 시스템 CBS · 상위 [PPV(단건) 프로모션 정책](PPC-P-30)

## 요약

PPV 쿠폰은 CBS **쿠폰 적용대상 관리** 에서 쿠폰이 쓰일 컨텐츠 범위를 좁힐 수 있다. 범위가 넓은 순서로 **전체 → 메타유형 → 카테고리 → CP → 시리즈 → 컨텐츠** 이다.

## 매핑대상구분 (PPV 해당)

| 구분 | 적용 범위 | 예시 |
| --- | --- | --- |
| **전체** | 모든 PPV 컨텐츠 (PPM 상품에는 미적용) | — |
| **메타유형** | 특정 메타 유형 컨텐츠 | 영화, 드라마, 예능, 교양 |
| **카테고리** | 특정 카테고리에 매핑된 컨텐츠 | 한국영화, 해외영화, MBC, KBS, 애니메이션 |
| **CP** | 특정 '컨텐츠 계약처명'이 공급한 컨텐츠 | — |
| **시리즈** | 에피소드 상위 시리즈 단위 | '김부장' 선택 시 1~10회차 모두 적용 |
| **컨텐츠** | VOD 단건 컨텐츠 1개 단위 (단건 쿠폰만 가능) | — |

> CP·카테고리·시리즈·메타유형은 기능 추가로 새로 생긴 구분이다.

## 공통 제약 조건

- **가격대**: 쿠폰 사용 가능한 가격대 지정 (미설정 시 금액 제한 없음)
- **요일·시간**: 특정 요일(월~일)·시간대 지정 가능 (기본값 제한 없음)
- 적용대상은 **승인 완료 후에도 수정 가능** 하며, 수정하면 **이미 발급된 쿠폰에도 바로 적용** 된다.
