> 적용대상 **PPM 전용** · 관련 시스템 CBS · 상위 [PPM(월정액) 프로모션 정책](PPC-P-20)

## 요약

'다크패턴' 법 시행으로, 쿠폰을 사용해 월정액에 가입한 고객에게는 **정가 전환동의**를 받아야 한다. 동의를 받지 못하면 **프로모션 적용 종료 시점에 해당 월정액이 자동 해지** 된다.

## 기준

| 항목 | 기준 |
| --- | --- |
| 전환 미동의 시 자동 해지 | **전체 UI** 에 적용 |
| 전환동의 팝업 온스크린 노출 | **UI 5.4.3 이상** 에만 적용 |
| 전환동의 요청 가능 시점 | 현행법상 전환 시점 **30일 이전** 부터 |

> UI 5.4.3 미만 고객은 팝업으로 동의를 받을 수 없지만 자동 해지는 똑같이 적용된다. 타겟 설계 시 UI 버전 분포를 반드시 확인한다.

## CBS 설정 — 다크패턴 적용 제외여부

쿠폰 정책 생성 시 CBS의 **다크패턴 적용 제외여부** 값으로 동작이 결정된다.

| 설정 | 동작 |
| --- | --- |
| **N** (기본) | 쿠폰 적용 만료 30일 전부터 전환동의 팝업 발생. 미동의 시 자동 해지 |
| **Y** | 만료 전 전환동의 팝업이 뜨지 않음. 고객이 해지하지 않으면 유료로 자동 전환 |

- 해지방어 쿠폰과의 조합은 [해지방어 쿠폰 운영](PPC-P-24) 참고
- 필드 상세: [CBS 쿠폰정책 핵심 필드·부가기능](PPC-CBS-02)

## 관련 기준

- '개월' 단위 쿠폰의 한계와 일자별 쿠폰 개발 계획 → [30일 이하 월 운영 기준](PPC-P-22)
