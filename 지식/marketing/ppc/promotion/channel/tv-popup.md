> 적용대상 **공통** · 관련 시스템 ACS · 상위 [프로모션 정책·업무](PPC-P-00)

## 요약

TV팝업은 **STB 종류와 UI 버전에 따라 쓸 수 있는 버튼이 다르다**. 팝업 기획 전에 버튼별 지원 범위를 확인한다.

## 버튼별 지원 범위

| 버튼 | 지원 조건 | 주의 |
| --- | --- | --- |
| 바로가기 | UI 5.1.3 이상 | **HD 셋톱, UI 5.2.0 미지원** |
| 가입하기 | UI 5.4.1 이상 | |
| 응모하기 | *(원문 버전 미기재 — 보완 필요)* | |

> **HD 셋톱** 은 랜딩 가능한 영역이 없어, 버튼이 보이더라도 **실제로 동작하지 않는다**.

## ACS 캠페인에서 TV팝업 쓰기

- ACS 채널 **TV 팝업 / OAP** 에서 상용 편성된 TV팝업 중 타겟팅할 팝업 ID를 매핑한다.
- 화면 하단 **메일 기안 UI** 로 편성 채널 담당자에게 연동 협조 메일을 즉시 상신한다.
- **피로도 정책**: 타겟팅 제외조건에서 **동일 캠페인 접촉 제외** 와 **TV팝업 2주 2회 제외** 를 체크해 민원을 예방한다.
- 상용 발송 전 본인 테스트 STB로 노출을 확인한다. → [ACS 테스트 STB 검증](PPC-ACS-06)
