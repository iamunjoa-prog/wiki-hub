## 요약

기획·타겟팅이 끝난 캠페인을 상용 발송 전에 **본인 테스트 단말로 검증** 하고 **승인을 상신** 하는 절차다.

## 1. 테스트 STB 발송 검증

1. 채널 설정 화면 하단 **[TV팝업 테스트 발송]** 영역으로 이동
2. 테스트그룹을 **전체** 로 지정 → **[테스트 STB 목록 출력]** (본인 사번에 미리 연결된 단말 조회)
3. **[테스트 발송]** → 본인 테스트 단말에 팝업·토스트가 규격대로 뜨는지 **직접 눈으로 확인**

**단말이 이상하면 (자가 조치)**

- [캠페인 관리] > **[STB 관리]** 에서 본인 단말 식별자(STB_ID)와 가입 서비스관리번호가 **1:1로 매핑** 되어 있는지 확인

## 2. 승인 기안 요청

1. GNB **[승인]** 탭 → 기안 요약 Comment 작성
2. 결재 라인 확인: **BTV 캠페인 관리자(김*복 매니저)** 및 **VOD**팀 팀장**
3. **[승인요청]** 상신

> **필수**: 상신 직후 사내 메일로 **류*영 매니저** 에게 검토 협조 메일을 보낸다. 본문에 **1) 캠페인명 2) 쿠폰정책번호 3) 정산방식** 을 적는다. → [담당자·결재 라인](PPC-R-02)

## 승인요청 후 수정

승인요청 상태가 되면 캠페인 데이터가 **잠금(읽기 모드)** 된다. 수정하려면 **승인요청취소** 를 먼저 해야 수정 메뉴가 다시 열린다.
