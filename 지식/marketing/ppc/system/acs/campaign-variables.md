> 적용대상 **공통** · 관련 시스템 ACS · 상위 [ACS 개요](PPC-ACS-01)

| 항목 | 설정값 | 설명 |
| --- | --- | --- |
| **캠페인 분류** | 월정액 / PPV 매출증대 / 고객구조개선 / 공지 | 분류에 따라 선택 가능한 상품 풀이 엄격히 제한됨. **월정액** → 월정액 상품만, **PPV** → 단건 PPV VOD만 → [상품 분류 체계](PPC-P-11) |
| **캠페인 기간** | 시작일 / 종료일 | **시작일**: 대상 모수를 추출해 쿠폰 시스템·채널로 발송하는 기준일. **종료일**: 구매 반응·성과 수집 마감일 |
| **기간 유형** | 일회성 / 주기성 | 일회성: 시작일에 1회 추출·실행. 주기성: 일정 간격 반복 (배치 스케줄링) |
| **공휴일 처리** | 공휴일 포함 / 공휴일 배제 | 주기성 캠페인 실행일이 공휴일이면 당일 발송할지, 다음날·전날 실행할지 선택 |
| **실험군/대조군 비율** | 슬라이더 또는 숫자 (예: 10) | 성과 검증용으로 오퍼를 보내지 않을 대조군 비율. **실험군:대조군 = 90:10 권장** |
| **최종 조정 고객 수** | 조정 안함 / 100,000명 / 200,000명 등 | 추출 모수가 예산·시스템 한계를 넘으면 설정 수만큼 **랜덤 캡핑** |
