## 요약

단발성 프로모션에서 **기본 기획 → 가입자 추출 → 오퍼 → 접점 채널** 을 한 흐름으로 연결하는 표준 절차다.

**1단계 캠페인 기본 기획 → 2단계 타겟팅 조건 설계·대상 추출 → 3단계 오퍼 매핑 → 4단계 접점 채널 설정**

> 사전 조건: 사용할 쿠폰 정책이 CBS에서 **승인 완료** 되어 있어야 한다. → [CBS P1](PPC-CBS-04)

## 단계별 절차

| 단계 | 화면 | 작업 | 주의사항 |
| --- | --- | --- | --- |
| **1. 기본 기획** | 간편 캠페인 등록 (기본 정보) | 캠페인 분류(예: 월정액) 선택 → 기간 설정 → 대상 상품(예: JTBC 월정액) 매핑 → 저장 | 오퍼 매핑 **후에** 기본 정보의 대상 상품을 수정·삭제하면 **저장된 오퍼 정보가 강제 초기화** 된다. 기획을 확정한 뒤 조작할 것 |
| **2. 타겟팅** | 타겟팅 설정 | 쿼리 템플릿(예: 고객프로파일_일별) 선택 → 필수값(★) 입력 → **[추출실행]** 으로 모수 확인 → 대조군 비율(예: 10%) 입력 | **피로도 정책 필수**: 제외조건 탭에서 **동일 캠페인 접촉 제외** 와 **TV팝업 2주 2회 제외** 체크 |
| **3. 오퍼** | 오퍼 설정 | 쿠폰/포인트 탭 → 정책 검색 → 유효기간·할인율 설정 → **[할당]** → 하단 목록에 추가됐는지 확인 | 쿠폰 적용 상품은 1단계에서 매핑한 상품 풀과 자동 동기화. **중복 발송 허용여부는 '불가' 권장** |
| **4. 채널** | 접촉 채널 설정 | 드롭다운에서 채널 선택(예: v5.0 토스트 팝업) → 랜딩 바로가기 유형 지정 → 이미지 업로드 | 모바일 푸시 본문의 모든 링크는 **단축 URL** 로 변환 |
