> 적용대상 **공통** · 관련 시스템 ACS · 상위 [ACS 개요](PPC-ACS-01)

## 요약

**시나리오 캠페인** 은 하나의 캠페인 안에서 여러 가입자 세그먼트·여러 채널·후속 Wave(반응 여부 추적)를 캔버스에 노드로 그려 설계하는 방식이다.

## 모델링 절차

1. GNB **[시나리오 캠페인 등록]** → 캠페인 기본 기획 정보 저장
2. 좌측 컴포넌트 목록에서 노드를 끌어 우측 캔버스에 **드래그 앤 드롭**
3. 노드 테두리에 마우스를 올리면 나오는 연결 포인트를 클릭한 채 다음 노드로 드래그 → **링크 선(화살표)** 생성

## 노드 종류

| 노드 | 역할 | 설정 방법·조건 |
| --- | --- | --- |
| **Campaign Start** (초록) | 시나리오 전체 작동 스케줄·주기 정의 | 캔버스당 **1개만**. 더블클릭 → 속성 창에서 되풀이 여부, 수행 주기(예: 매일, 특정 요일), 가동 시각 입력 |
| **비즈니스 쿼리** (빨강) | 가입자 추출 조건 | 속성 창에서 마트 템플릿·변수 조건 입력 후 **[실행]** 을 눌러야 가동. 검증되면 우측 상단 **초록 체크** 표시 → [쿼리 유형](PPC-ACS-04) |
| **Join** | N개 고객군 결합 | 교집합, 차집합, 합집합-교집합, 기준유지 등. **조인 키 매핑 필수**: 좌측 기준 컬럼(예: CUST_ID)을 대상 컬럼의 CUST_ID 위로 드래그 드롭 |
| **Multi-Step** | 1차 발송 반응을 보고 2차 Wave 설계 | 속성 창에서 **반응이력사용** 체크 → 이전 캠페인 반응 유형(예: 채널미반응자, 구매미반응자) 선택 → 일정(예: 실행일 이후 1일 후) 지정 → 아래에 새 오퍼·채널 노드 연결 |

## 관련 문서

- 준실시간 쿼리와 배치 쿼리를 한 캔버스에 섞으면 안 되는 이유 → [ACS 예외처리](PPC-ACS-08)
