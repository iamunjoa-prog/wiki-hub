> 적용대상 **공통** · 관련 시스템 ACS · 상위 [ACS 개요](PPC-ACS-01)

## 요약

준실시간 가입자 이벤트 수집 고도화(**NaviLog 2.0**)로, 타겟팅 캔버스에서 가입자 행동을 준실시간으로 포착하는 쿼리 템플릿이다. 조회 범위는 **수행 시점 기준 최대 24시간** 이내 로그다.

## 쿼리 목록

| 쿼리명 | 포착하는 행동 | 활용 예시 |
| --- | --- | --- |
| **실시간시청_타게팅_V2** | 편성표 진입, 채널 선택, 미니편성표 노출 | STB 구동 후 전체편성표 메뉴에 진입한 가입자 |
| **VOD시청_타게팅_V2** | VOD 재생 시작, 이어보기, 연관 영상 선택 | 특정 VOD(예: 베놈2) 시놉시스 진입 후 예고편을 재생한 가입자 |
| **메뉴이동_타게팅_V2** | 홈, OCEAN, 영화, 월정액 등 메뉴 이동 | OCEAN 월정액 홈의 '새로 들어온 영화' 블록에 진입한 가입자 |
| **시놉시스_타게팅_V2** | 단편·시즌 시놉시스 진입, 줄거리·더보기 선택 | 영화 상세 시놉시스에서 구매하기 버튼을 누른 가입자 |
| **콘텐츠선호도_타게팅_V2** | 찜하기, 좋아요, 리뷰 입력 | 시놉시스 평점 창에서 리뷰·별점을 남긴 가입자 |
| **검색_타게팅_V2** *(신규)* | 통합검색 진입, 키워드 입력, 결과 선택 | 검색 결과에서 특정 VOD를 선택한 가입자 |
| **구매_타게팅_V2** | 결제창 진입, 구매 시도·완료·취소 | 결제 팝업까지 들어왔다가 결제하지 않고 취소한 가입자 |
