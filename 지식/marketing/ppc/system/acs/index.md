> 적용대상 **공통** · 관련 시스템 ACS · 상위 [시스템 매뉴얼](PPC-S-00)

## 요약

**ACS(Advanced Campaign System, 통합 캠페인 시스템)** 는 마케터가 가입자 타겟팅을 설계하고, 할인 오퍼(쿠폰)를 할당하고, TV팝업·토스트 팝업·모바일 푸시 등 접점 채널로 메시지를 발송·제어하는 시스템이다. 프로모션 운영 프로세스의 **Step 6 캠페인 실행** 단계에서 쓴다.

## 메뉴 구성 (GNB)

| 대분류 | 상세 화면 | 역할 |
| --- | --- | --- |
| **간편 캠페인 등록** | 간편 캠페인 등록 | 기본 기획, 타겟팅 쿼리 적용, 오퍼 매핑, 전송 채널 연결을 한 흐름으로 |
| **캠페인 관리** | 캠페인 조회(전체) / 타겟리스트 관리 / 승인 관리 / STB 관리 / 고객그룹 / 관심고객관리 | 캠페인 현황 조회, 타겟리스트 병합, 대체 결재자 설정, 테스트 STB·제외 대상 관심고객 관리 |
| **준실시간 캠페인 관리** | 준실시간 캠페인 등록 / 캠페인 조회 | 실시간 시청·이동 이벤트 기반 타겟팅 시나리오 설계·모니터링 |
| **모니터링** | 캠페인정보 전송 모니터링 / 캠페인 수행 현황 / 채널 발송 모니터링 / 캠페인 실행분석 | 발송 성과 분석, 가입자별 제외 사유(피로도 필터링 등), 오류 추적 |
| **캠페인 성과 조회** | 월간 리포트 / 매출 리포트 / 단기성과 / 장기성과 | 채널·VOD 시청·구매 성과, 실험군-대조군 비교, 중장기 잔존율 |
