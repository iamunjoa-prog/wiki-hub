> 적용대상 **공통** · 관련 시스템 Swing · 상위 [Swing 개요](PPC-SWG-01)

## 요약

공지요청 전에 등록 화면 하단 **'체크리스트'** 버튼으로 12개 항목의 체크결과를 **예 / 아니오 / 해당없음** 중 하나로 선택하고 저장한다.

> - 체크결과가 적합하지 않으면 저장 후 공지요청을 해도 **체크리스트가 다시 뜬다**.
> - **①번 항목에 '아니오'를 선택하면 다음 단계로 진행할 수 없다.**

## 체크리스트 12개 항목

| # | 질문 |
| --- | --- |
| ① | **개인 고객에 대한 이슈는 없는가?** (명의도용, 임의가입, 개인정보 유출 등) |
| ② | 기존 고객에 대한 이용자 차별 항목은 없는가? |
| ③ | 기존 고객이 서비스를 이용하는 데 불편함은 없는가? |
| ④ | 서비스에 대한 안전성은 확보되었는가? (사전 Test 등) |
| ⑤ | 서비스 이용을 위해 별도 고객 동의가 필요 없는가? — 서비스 신청·해지·응대 신청권자 범위 확인 |
| ⑥ | 고객에게 사전 커뮤니케이션이 진행되는가? (E-mail, SMS 등) — 커뮤니케이션 내용 첨부 |
| ⑦ | 홈페이지에 공지가 되었는가? |
| ⑧ | 방송통신법, 공정거래법 등 GR 이슈는 없는가? (방통위 가이드 준수) |
| ⑨ | 이용약관 준수 및 신고가 완료되었는가? |
| ⑩ | 재판매 고객에게도 동일하게 적용하는가? |
| ⑪ | VoC 발생이 예상되며 처리 방안(응대 시스템)은 준비되어 있는가? |
| ⑫ | 전산으로 처리 불가한 경우에 대한 처리 방안은 준비되어 있는가? |

## PPC 프로모션에서 특히 볼 항목

| 항목 | 연결되는 PPC 기준 |
| --- | --- |
| ② 이용자 차별 | 타겟 한정 쿠폰·배너 프로모션인 경우 대상 선정 기준 확인 |
| ④ 사전 Test | 테스트 STB 발송 검증 → [ACS P2](PPC-ACS-06) |
| ⑤ 별도 고객 동의 | 월정액 정가 전환동의 → [다크패턴 대응](PPC-P-21) `[PPM]` |
| ⑧ GR 이슈 | 다크패턴 규제 → [다크패턴 대응](PPC-P-21) `[PPM]` |
| ⑪ VoC 대비 | UI 버전 미지원 고객의 쿠폰 미적용 등 → [UI 버전표](PPC-R-01) |
| ⑫ 전산 처리 불가 | 기발급 쿠폰 만료는 CSR 처리 → [CBS P3](PPC-CBS-06) |

> 위 연결표는 PPC 관점에서 참고용으로 정리한 것이다. 체크 기준 자체는 원문 12개 항목을 따른다.
