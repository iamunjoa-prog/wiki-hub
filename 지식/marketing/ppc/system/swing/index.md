> 적용대상 **공통** · 관련 시스템 Swing · 상위 [시스템 매뉴얼](PPC-S-00)

## 요약

**Swing 접점공지** 는 프로모션·상품 변경 내용을 **고객센터 상담원(상담M)** 이 알 수 있도록 전파하는 공지 요청 기능이다. 프로모션 운영 프로세스의 **Step 4 Swing 공지** 에 해당한다. 고객이 쿠폰·할인을 문의했을 때 상담원이 응대할 수 있도록 **프로모션 시작 전에** 공지가 전파되어 있어야 한다.

## 접속 경로

**Swing ▶ PLM(상품관리) ▶ 접점공지 ▶ 접점공지 등록요청**

> 등록 화면에서 **주황색 영역은 필수 입력** 항목이다.

## 전체 흐름

1. **등록 요청서 작성** — 공지 구분, 유형, 대상, 기간, 제목·본문 입력 → [등록 입력 항목](PPC-SWG-02)
2. **체크리스트 작성·저장** — 12개 항목 체크 → [사전 체크리스트](PPC-SWG-03)
3. **공지요청** — 요청 후에는 **수정 불가**
4. **고객센터 검토·등록** — 아래 참고

## 공지요청 이후 프로세스

| 순서 | 담당 | 내용 |
| --- | --- | --- |
| ① | 고객센터(이**컴) 접점공지 승인권한자 | 1차 확인 — **승인 또는 반려** |
| ② | 고객센터(이**컴) 담당자 | 2차 확인 → 등록자와 **MKIS 등록 내용 최종 확인** (NateOn 쪽지로 전달) → 사업부서 확인 |
| ③ | 사업부서 | confirm 완료된 내용으로 **MKIS 등록·공지** |

> 등록자는 ②단계에서 NateOn 쪽지로 오는 MKIS 등록 내용 확인 요청에 응답해야 공지가 최종 게시된다.

## PPC 프로모션과 연결되는 준비 사항

- 상담원이 직접 쿠폰을 발급해야 하는 프로모션이면 **CBS 상담원 권한 설정** 을 미리 준비한다. 상담원 ID는 **A→B 순서 규칙** 을 지킨다. → [CBS 발급 방식별 가이드](PPC-CBS-07)
- 공지 요청일은 고객센터 **전파 완료 기한** 이므로 프로모션 시작일보다 앞서게 잡는다.
