> 적용대상 **공통** (일부 필드 `[PPM]`) · 관련 시스템 CBS · 상위 [CBS 개요](PPC-CBS-01)

쿠폰정책 / B캐쉬 / B포인트 상품관리 화면에서 입력하는 필드다.

## 기본 필드

| 항목 | 설정값 | 설명 |
| --- | --- | --- |
| **쿠폰 구분** | 일반 / 개통프로모션 / 일반프로모션 | 프로모션 성격에 따른 분류. **일반적인 온스크린 프로모션은 모두 '일반'** |
| **쿠폰 종류** | 할인권 / 이용권 | 이용권은 사용 가능 디바이스가 **MOBILE일 때만** 사용 가능 |
| **발급 방법** | ① 관리자 ② 인증번호 ③ 상담원 | 아래 '발급 방법' 참고 |
| **유효기간 설정방식** | ① 고정 ② 유동 | *(원문 설명 미기재 — 보완 필요)* |
| **적용 요금제** | 건단위 — PPV 쿠폰 / 월단위 — PPM 쿠폰 | 프로모션 대상 VOD 요금제 유형 → [상품 분류 체계](PPC-P-11) |
| **중복 발급 가능 여부** | Y / N | N: 동일 고객에게 1~4건만 발급(제한 건수 설정 가능). Y: 제한 없이 중복 발급(단, 중복발급체크기간 기준. '0일'이면 무제한) |
| **최대 발급 수량** | 숫자 | 이 값을 넘으면 추가 발급이 **원천 차단** |
| **판매소 노출 여부** | Y / N | Y면 UI 쿠폰판매소에 노출 (**현재 미사용**) |
| **상품 유형** | VOD 상품 유형 (최소 1개) | 쿠폰을 쓸 수 있는 상품 유형 (PPV, PPS, PPM 등) |

### 발급 방법

| 방법 | 설명 | 주 용도 |
| --- | --- | --- |
| **관리자 발급** | 쿠폰 생성 담당자가 직접 발급. 실제 발급은 캠페인 시스템(ACS)에서 진행하며, 엑셀 업로드 발급도 가능 (서비스관리번호 기준) | 온스크린·타겟 프로모션 |
| **인증번호 발급** | 난수 인증번호를 생성해 고객이 STB나 상담원을 통해 등록 | 오프라인·STB 외 프로모션 |
| **상담원 발급** | 유통망을 지정하고 소속 상담원에게 권한 할당. 106 상담사가 직접 쿠폰 적용·발급 | 고객센터 응대 |

상세 절차: [발급 방식별 가이드](PPC-CBS-07)

## 고도화 부가기능

| 기능 | 적용 조건 | 동작·주의 |
| --- | --- | --- |
| **모바일전용발급여부** | 인증번호 발급일 때만 체크 가능 | 체크 시 STB에서는 인증번호 등록 불가. Mobile B tv와 상담원으로만 발급 |
| **프로필 중복가능** | Y / N | Mobile B tv 프로필별 중복 발급 체크. N: 프로필당 1건 / Y: 제한 없음. ※ 관리자 예약발급, CPAS 연동, Mpoc 인증 시 **프로필 ID 값이 있을 때만** 동작 |
| **할인금액 제한여부 / 최대할인금액** | 정율 할인 + 제한여부 Y | 할인액이 최대할인금액을 넘지 않음. 예: 100% 할인·최대 5,000원 쿠폰을 8,000원 상품에 쓰면 5,000원만 할인 (VAT 제외) |
| **사용횟수 제한여부 / 최대 사용횟수** | 제한여부 Y | 설정 횟수만큼만 사용 가능. ※ STB·상담원·다회선·Mpoc 화면에서만 적용 (**기존 상품 자동적용 시 무시**) |
| **다크패턴 적용 제외여부** `[PPM]` | Y / N | Y: 만료 전 전환동의 팝업 없이 자동 유료 전환. N: 만료 30일 전부터 전환동의 팝업, 미동의 시 자동 해지 → [다크패턴 대응](PPC-P-21) |
| **해지방어여부** `[PPM]` | Y / N | Y: 해지방어 쿠폰 수령 시 기존 쿠폰을 전환동의 처리. 해지방어 쿠폰 종료 시에도 동의를 받지 않으려면 다크패턴 적용 제외여부 Y 추가 → [해지방어 쿠폰](PPC-P-24) |
