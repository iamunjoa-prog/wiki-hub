> 적용대상 **공통** · 관련 시스템 CBS · 상위 [CBS 개요](PPC-CBS-01)

## 요약

쿠폰을 쓸 수 있는 **세부 제약 조건** 을 설정하고 **대상 상품·컨텐츠를 매핑** 하는 화면이다. 적용대상을 등록하지 않으면 **승인요청을 할 수 없다.**

## 제약 조건

| 항목 | 설명 | 기본값 |
| --- | --- | --- |
| 가격대 | 쿠폰을 쓸 수 있는 가격대 | 제한 없음 |
| 사용 가능 요일·시간 | 특정 요일(월~일)·시간대 | 제한 없음 |

## 매핑대상구분

| 구분 | 적용 범위 | 사용 가능 쿠폰 |
| --- | --- | --- |
| **상품** | 특정 상품 (쿠폰 정책 생성 시 PPM 선택) | PPM 중심 |
| **약정** | 특정 약정(3/6/12개월). 해당 약정 외 다른 약정·무약정에는 적용 불가 | **월정액 쿠폰만** |
| **전체** | 모든 PPV 컨텐츠 (PPM 상품에는 미적용) | PPV |
| **컨텐츠** | VOD 단건 컨텐츠 단위 | **단건 쿠폰만** |
| **CP** *(추가)* | 특정 '컨텐츠 계약처명' 공급 컨텐츠 | PPV |
| **카테고리** *(추가)* | 특정 카테고리 매핑 컨텐츠 (한국영화, 해외영화, MBC, KBS, 애니메이션 등) | PPV |
| **시리즈** *(추가)* | 상위 시리즈 단위 ('김부장' 선택 시 1~10회차 전체) | PPV |
| **메타유형** *(추가)* | 특정 메타 유형 (영화, 드라마, 예능, 교양 등) | PPV |

> 무약정 쿠폰을 발급한 경우에는 **약정 상품 구매에도** 쓸 수 있다.

## 수정 규칙

- 적용대상이 입력된 상태에서는 **쿠폰 정책을 수정할 수 없다.** 정책을 고치려면 적용대상을 먼저 삭제한다.
- 적용대상은 **승인 완료 후에도 수정 가능** 하며, 수정하면 **이미 발급된 쿠폰에도 즉시 반영** 된다.
