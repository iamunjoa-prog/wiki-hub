> 적용대상 **공통** · 관련 시스템 CBS · 상위 [CBS 개요](PPC-CBS-01)

## 요약

승인 완료된 쿠폰·B캐쉬를 CBS에서 **직접** 고객에게 지급하는 방법이다.

> **대량 쿠폰 발급은 대부분 ACS로 한다.** → [ACS 간편 캠페인 등록](PPC-ACS-05)

| 방식 | 언제 쓰나 |
| --- | --- |
| 관리자 예약 발급 | 타겟 리스트를 뽑아 일괄 지급 |
| 상담원 예약 발급 | 고객센터 상담원이 통화 중 즉시 지급 |
| 인증번호 발급 | 인쇄물·제휴사 프로모션으로 코드를 먼저 배포 |

## 1. 관리자 예약 발급

발급 방법이 **'관리자발급'** 인 정책에서 사용한다.

**대량 발급 (엑셀 업로드)**

1. 쿠폰/포인트 발급관리 메뉴 → 관리자발급 정책 선택
2. **Sample** 버튼으로 업로드용 표준 엑셀 양식 다운로드
3. 엑셀에 고객 **서비스관리번호** 기입 → 업로드 → 즉시/예약 발급

**소량 발급 (10건 이하)**

- 엑셀 없이 팝업창에 서비스관리번호를 직접 입력해 발급

## 2. 상담원 예약 발급 및 권한 설정

발급 방법이 **'상담원발급'** 인 정책에서 사용한다.

**발급**

1. 상담원발급 정책 선택
2. 배포할 유통망 지정 → 배포 수량 입력 → 즉시발급 또는 예약발급
3. 여러 유통망에 대량 배포할 때는 **유통망엑셀발급처리** 체크 후 엑셀 업로드

**상담원 권한 설정**

1. 예약발급 버튼 옆 **상담원권한설정** → **신규**
2. 정책 상세와 대상 상담원 ID 입력 → 저장

**상담원 ID 입력 규칙 (중요)**

| 규칙 | 내용 |
| --- | --- |
| **A** | ID 앞자리가 **300B** 이면 **30B** 로 바꿔 입력 |
| **B** | ID가 **10자리를 넘으면 앞 10자리까지만** 입력 |
| **C** | 반드시 **A → B 순서** 로 적용 |

> 예시(가상 ID): 300B12345678 → A 규칙 적용 30B12345678 (11자리) → B 규칙 적용 30B1234567 (10자리)

> 대상 ID를 할당하면 **권한을 받은 상담원 외에는 쿠폰을 적용(발급)할 수 없다.**

## 3. 인증번호 발급

인쇄물·제휴사 프로모션으로 **난수 코드를 먼저 배포** 하고 고객이 직접 등록하게 한다.

- 발급 수량만 입력하면 고유 인증번호가 대량 생성·발급된다 (쿠폰 상태 **'등록'**).
- 시스템 구조상 **소량 발급 기능은 없다.**
- 모바일 전용으로 제한하려면 **모바일전용발급여부** 체크 → [CBS 핵심 필드](PPC-CBS-02)
