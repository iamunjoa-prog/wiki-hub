> 적용대상 **공통** · 관련 시스템 CBS · 상위 [시스템 매뉴얼](PPC-S-00)

## 요약

**CBS(Contents Billing System, 가입자관리시스템)** 는 프로모션용 **쿠폰, B캐쉬, B포인트** 를 생성·승인·발급·관리하는 사내 시스템이다. 프로모션 운영 프로세스의 **Step 3 쿠폰 생성** 단계에서 쓴다.

## 접속 정보

| 항목 | 내용 |
| --- | --- |
| 시스템 명칭 | CBS (Contents Billing System) |
| 상용 URL | (사내 CBS 상용 URL · 생략) |
| 주요 용도 | 쿠폰, B캐쉬 생성 |
| 세부 매뉴얼 | CBS_쿠폰 관리 시스템_사용자매뉴얼(User Guide)_V3.1.doc → [원본 매뉴얼·첨부](PPC-D-01) |

> B포인트도 생성할 수 있으나 **현재 실무에서는 B포인트를 쓰지 않아** 본 가이드에서 제외했다.

## 메뉴 구성

| 대분류 | 상세 화면 | 역할 |
| --- | --- | --- |
| **쿠폰 관리** | 쿠폰정책관리 / 쿠폰적용대상관리 / 쿠폰승인현황관리 / 쿠폰발급관리 / 프로모션쿠폰관리 | 쿠폰 정책 생성·승인·발급, 프로모션 연동, 대상 매핑 |
| **B캐쉬 관리** | B캐쉬상품관리 / B캐쉬승인현황관리 / B캐쉬발급관리 | B캐쉬 상품(판매용/판촉용) 정책 수립·승인·발급 |
| **현황 및 배포 관리** | 예약발급 현황관리 / 유통망발급현황 | 즉시·예약 발급 상태 모니터링, 대리점·지점(유통망)별 수량 관리 |
