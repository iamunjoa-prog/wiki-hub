> 적용대상 **공통** · 관련 시스템 CBS · 상위 [CBS 개요](PPC-CBS-01)

## 요약

신규 프로모션에서 **가장 먼저** 하는 프로세스다.

**1단계 정책 등록 → 2단계 적용대상 등록 (쿠폰 필수) → 3단계 승인요청 → 4단계 승인 완료 후 랜딩·추천순위 설정**

> 사전 조건: **시행 품의 승인 후** 에 등록한다. 품의 승인 전 CBS 선등록은 자제한다. → [운영 프로세스 Step 2](PPC-P-12)

## 단계별 절차

| 단계 | 화면 | 작업 | 주의사항 |
| --- | --- | --- | --- |
| **1. 정책 등록** | 쿠폰/B캐쉬 상품관리 → **신규** 또는 **복사** | 대/중/소분류 지정 → 정책 기본정보 입력 → 저장 | **쿠폰정책 시작/종료일** = 고객이 쿠폰을 등록(인증)할 수 있는 기간. **유효기간** = 등록 후 실제 사용 가능한 기간 |
| **2. 적용대상 등록** | 쿠폰적용대상관리 | 검색으로 정책 조회 → 적용대상 탭에서 매핑대상구분 선택 → 대상 등록·저장 | **필수**. 없으면 승인요청 불가. 적용대상이 있으면 정책 수정 불가 (수정하려면 적용대상 삭제) |
| **3. 승인요청** | 쿠폰정책관리 (또는 각 상품관리) | 정책 조회·선택 → 화면 하단 **승인요청** | 승인요청 상태부터 **정책 수정 불가**. 승인 후 기본 정책 수정은 **CSR** 로 별도 요청. 적용대상은 승인 후에도 수정 가능 (기발급 쿠폰에 즉시 반영) |
| **4. 랜딩·추천순위** | 쿠폰랜딩설정관리 / 쿠폰추천순위관리 → 신규 | 정책 기본정보 입력 → 저장 | **승인 완료 후** 설정 가능. 아래 참고 |

## 4단계 상세

- **쿠폰 랜딩 설정 (필수)**: 설정해야 쿠폰함과 스마트알림에 **[쿠폰 사용하기]** 버튼이 노출된다. 사용률에 직접 영향을 준다.
- **쿠폰 추천순위**: 등록하면 쿠폰함 기본 노출 순위보다 우선 노출된다. 노출 순서: **추천순위 > 만료임박순 > 할인율순**
