# 지식 문서 폴더

지식 허브 웹앱이 읽어들이는 마크다운 문서가 들어 있다.
**폴더가 곧 메뉴**이고, 파일 하나가 문서 하나다.

| 폴더 | 메뉴 | 내용 |
| --- | --- | --- |
| `programming/` | 편성 | 장르별 편성 인사이트, 편성 정책 *(문서 준비 중)* |
| `promotion/` | 프로모션 | PPC 프로모션 정책·업무, 담당자, 용어, FAQ |
| `system/` | 시스템 매뉴얼 | ACS · CBS · Swing 조작법 |
| `guide/` | 이용 안내 | 허브 사용법, 수정 절차, 작성 규칙 |

## 작성 규칙

형식 규약(프론트매터 필드, 상태 표기, 문서 간 링크, 사내 정보 주의)은
웹앱의 **이용 안내 › 문서 작성 규칙** 문서([`guide/writing.md`](guide/writing.md))에 정리돼 있다.

프론트매터를 못 채워도 괜찮다. 본문만 넣어 주면 나머지는 채워 드린다.

## 사내 정보 주의

실제 사내 문서를 넣기 전에 **외부 반출이 가능한 범위인지 확인한다.**
실명·부서명·사내 URL·제휴 캠페인명은 가린 뒤 넣는다. 자세한 기준은 위 작성 규칙 문서를 본다.
