> 적용대상 **공통** · 관련 시스템 ACS
>
> **이 문서가 배너 스펙의 유일한 기준이다.** 개별 구좌 문서에 글자수를 중복 기재하지 않는다. UI 버전별 기능 지원은 [UI 버전별 지원 현황표](PPC-R-01)와 맞춘다.

## 이 문서는

전 배너의 **텍스트 글자수 제한, 편성 가능 영역, 타겟팅 가능 여부, 최소 UI(sw) 버전, 랜딩 기능**을 모은 스펙표다.

카피를 다 써놓고 글자수 초과로 갈아엎는 일을 막고, **UI 버전 미달이면 배너가 아예 노출되지 않으므로** 기획 단계에서 검증하기 위한 문서다.

- 카피 확정 **직전** — 글자수 검증
- 구좌 선택 **직후** — 타겟팅 가능 여부, UI 버전 검증

### TV 팝업 랜딩 기능별 UI 버전 제약

| 기능 | 제약 |
| --- | --- |
| 바로가기 | 5.1.3 이상 가능. **단 HD 셋탑과 UI 5.2.0 미지원** |
| 응모하기 | **5.3.2 이상.** ⚠️ **HD 셋탑은 버튼이 노출돼도 동작하지 않는다**(랜딩 가능한 영역이 없음) — 응모형에는 HD 셋탑을 모수에서 **필수 제외** |
| 가입하기 | **5.4.1 이상** |

## 배너별 장단점

| 배너 | 장점 | 단점 |
| --- | --- | --- |
| **Today B tv** | 첫 화면 80%+ 차지. TV 켜자마자 노출되어 **효율 최고** | UI 5.4.1·5.4.2·5.6.1 이상이 상이해 **별도 이미지 제작 필요.** 제작 가이드가 엄격해 소요 기간 김 |
| **Today B tv+** | B tv+ 홈 배너 중 **효율 최고** | **B tv+ 가입자에게만** 노출 · UI **5.6.1 #2 이상**만 가능해 지원 UI가 전 배너 중 가장 높음 |
| **2단배너** | 콘텐츠 연관 마케팅 용이. 1~3단 이벤트블록 자유 구성. **UI 커버리지 최대** | 가장 평이한 스타일이라 가이드대로 만들면 주목도 낮음 |
| **띠배너** | Today B tv 바로 아래 편성 가능 → 실시간 홈 사용자도 첫 화면 노출 | 프리뷰가 없어 **텍스트만으로 후킹**해야 함 |
| **롱배너** | 이미지 위주 마케팅에 유용. 홈 이벤트 롱배너 영역 활용 | 텍스트 영역이 작음 |
| **빅배너 (홈)** | UI 530~540에서 홈 최상단 메인 노출 | **5.4.0까지만 지원.** 5.4.1 이상 고객에게는 **미노출** → 그 구간은 Today B tv 사용 |
| **빅배너 (장르)** | 영화·다시보기·애니 GNB 최상단 편성 가능. UI 상한 없음(5.3.0 이상) | 3-7 빅배너(홈)과 이름이 같아 혼동 주의 — 편성 영역·UI 범위가 다름 |
| **월정액 가입 빅배너** | 가입하기 버튼의 **쿠폰 반영 최저가**를 활용한 직접 마케팅 | 별도 랜딩 없이 구매창으로 이동해 전달 정보가 적음 |
| **풀프로모션배너** | 전면 활용으로 강조 효과 최대. 배경 3~4줄 + 배너별 1~2줄 | **상하 편성 블록이 아예 보이지 않음** |
| **시놉시스 배너** | 타이틀 연관 이벤트에 적합. 복수 타이틀에 동일 배너 편성 가능. Today B tv에 해당 타이틀 노출 시 함께 노출 (MASS 5.4.3+, TARGET 5.5.1+) | 영역이 작음 |
| **TV 팝업** | 켜자마자 전면 강제 노출 가능. 템플릿 없는 프로모션도 개발로 대응 | **개발 시 약 2주 소요.** 하위 UI 미작동이 많아 타겟이 줄어들 수 있음 |
| **미니 EPG / WING UI** | 실시간 채널 타겟에 유용. 채널별 배너 차등 설정 가능 | 카피 영역 매우 작음. **타겟팅 불가** |
| **편성표 배너** | 실시간 채널 타겟에 유용 | **타겟팅 불가** |

## 검증 체크리스트

카피 확정 전에 배너마다 확인한다.

- 각 텍스트 필드가 글자수 제한 이내인가? (공백 포함 여부 확인)
- 줄 수 제한을 지켰는가?
- TARGET 캠페인인데 타겟팅 불가 구좌를 넣지 않았는가?
- 캠페인 대상 셋탑의 UI 버전이 최소 sw_version 이상인가?
- 사용하려는 랜딩 기능이 해당 배너에서 지원되는가?
- TV 팝업 개발이 필요하다면 **2주 리드타임**을 일정에 반영했는가?
- Today B tv 사용 시 UI 버전별 별도 이미지 제작 일정을 확보했는가?

## 갱신 기준

UI 버전 정책이 바뀌면 규격표와 랜딩 기능표를 함께 갱신하고, [UI 버전별 지원 현황표](PPC-R-01)와 맞춥니다.

**아직 못 채운 것** — 글자수의 공백 포함 여부(현재 TV 팝업 버튼만 명시), 각 배너의 실제 이미지 픽셀 규격(TV 팝업 외에는 미기재).
