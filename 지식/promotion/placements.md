> 적용대상 **공통** · 관련 시스템 ACS
>
> 캠페인 목표·혜택 확정 후, 카피를 쓰기 **전에** 구좌를 먼저 정한다. [캠페인 플레이북](MKI-05)에서 베이스라인을 잡고 이 문서로 검증·조정한다.

## 이 문서는

B tv 화면에서 캠페인이 노출될 수 있는 자리들. 각 구좌는 크기·글자수 제한·타겟팅 가능 여부·지원 UI 버전이 다르다.

**구좌 선택이 캠페인 성과의 상한선을 정한다.** 아무리 좋은 카피도 잘못된 구좌에 넣으면 노출되지 않는다.

## 구좌 구조

### 1차 진입·노출 구좌

고객이 **최초로 캠페인을 만나는** 자리다.

- [Today B tv](MKI-B-02) — MASS / TARGET
- [Today B tv+](MKI-B-12) — B tv+ 가입자 전용, [Today B tv](MKI-B-02)와 구분
- [2단 배너](MKI-B-03)
- [롱배너](MKI-B-04)
- [빅배너](MKI-B-05)
- [띠배너](MKI-B-06)
- [오핫콘](MKI-B-11) — 배너 시안을 만들지 않는 구좌
- [실시간 채널 배너](MKI-B-10) — 미니 EPG / 편성표 / WING UI

### 2차 상세 랜딩 구좌

1차 구좌를 클릭한 고객이 **진입하는** 자리다.

- [풀페이지 배너](MKI-B-07)
- [시놉시스 배너](MKI-B-08)
- [TV팝업 규격](MKI-B-09)

> **풀페이지 배너는 최초 노출 구좌가 아니다.** 진입 구좌 없이 단독으로 시작하는 유저플로우를 만들지 않는다.

## 구좌 선택 기준

| 캠페인 목표 | 권장 구좌 조합 |
| --- | --- |
| 대규모 도달 · 신작 인지 | Today B tv MASS + 롱배너 + 오핫콘 |
| 특정 고객 대상 콘텐츠 홍보 | Today B tv TARGET + 롱배너 |
| 단순 구매 혜택 (할인·쿠폰·포인트백) | Today B tv(MASS/TARGET) + 2단 배너 → 시놉시스. **풀페이지 불필요** |
| 경품·복합 이벤트 (참여조건·지급일정 설명 필요) | Today B tv(MASS/TARGET) + 2단 배너 → 풀페이지 배너 |

### 풀페이지를 쓸까 말까

| 쓴다 | 안 쓴다 |
| --- | --- |
| 경품 종류·당첨 조건 상세 안내 필요 | 단순 할인·포인트백 |
| 혜택이 여러 개이거나 고객별 조건이 다름 | 시놉시스 배너만으로 조건·혜택·기간 전달 가능 |
| 참여 방법·지급 시점·당첨자 발표일·유의사항 필요 | 별도 이벤트 참여가 없음 |
| 진입 배너 카피만으로 설명이 불가능 | |

## 핵심 지표 정의

| 지표 | 정의 |
| --- | --- |
| **UV** | 해당 구좌를 이용한 순 이용자 수 |
| **PV** | 해당 구좌에서 발생한 이용량 |
| **PV/UV** | 이용자 1인당 평균 탐색량 |
| **매출** | 해당 구좌를 통해 발생한 구매 매출 |
| **UV당 매출** | 매출 ÷ UV. 방문자당 매출 효율 |
| **구매전환율** | 구매자 수 ÷ UV. **구매자 데이터가 있을 때만 사용** |

> **UV당 매출을 구매전환율이라고 표현하지 않는다.** 다른 지표다.

관찰 수치는 [실적 벤치마크](MKI-04)를 본다.

## 구좌별 카피 역할

역할을 분리해야 같은 캠페인의 여러 배너가 **같은 문장을 반복하지 않는다.**

| 구좌 | 카피 역할 |
| --- | --- |
| Today B tv MASS | 작품의 핵심 관전 포인트 + 주요 혜택을 전고객에게 명확히 |
| Today B tv TARGET | 타겟이 관심 가질 확인된 콘텐츠 특징 + 혜택 |
| 2단 배너 | **하나의** 핵심 프로모션 메시지와 진입 행동 |
| 롱배너 | 키아트·타이틀·관전 포인트 중심 콘텐츠 홍보 |
| 띠배너 | 텍스트 위주 후킹 (프리뷰 없음) |
| 오핫콘 | **카피를 제작하지 않음.** 타이틀·포스터로 안내 |
| 시놉시스 배너 | 구매 조건 + 혜택 + 기한 (전환형) |
| 풀페이지 배너 | 경품·참여 조건·지급 방식·유의사항 상세 |

## 유저플로우 원칙

- 상세 이벤트가 없으면 풀페이지를 불필요하게 추가하지 않는다.
- UI 템플릿 이미지와 실제 캠페인 소재를 구분한다.
- **존재하지 않는 배너 타입이나 이미지 경로를 임의로 만들지 않는다.**

## 규격 검증

카피를 확정하기 전에 반드시 **글자수·줄수·UI 버전·타겟팅 가능 여부**를 검증한다. → [배너 규격](MKI-B-01)

## 갱신 기준

- 새 구좌가 생기면 이 문서의 구조 목록·선택 기준·카피 역할 표에 모두 추가하고, 개별 문서를 만듭니다.
- 구좌별 상세 스펙은 개별 문서가 아니라 [배너 규격](MKI-B-01)에 모읍니다. 개별 문서는 **성격·적합 상황·카피 방향·유저플로우**를 다룹니다.

**아직 못 채운 것** — 구좌별 실제 편성 가용성(Capa) 조회 방법. 발송 Capa 기준은 [배너·TV팝업·스마트알림 운영 기준](PPC-R-06)에 있습니다.
