> 적용대상 **PPM 전용**(B tv+) · 관련 시스템 ACS · 규격은 [배너 규격](MKI-B-01)

## 이 문서는

B tv+ **가입자가 B tv+ 홈에 들어왔을 때** 첫 화면의 60% 이상을 차지하는 메인 배너. [Today B tv](MKI-B-02)의 B tv+ 전용 버전이다.

B tv+ 홈 배너 중 효율이 가장 높지만, **B tv+ 월정액 가입자에게만** 노출되고 지원 UI 버전도 가장 높다.

## 규격

| 항목 | 값 |
| --- | --- |
| 텍스트 규격 | 최대 3줄(타이틀 1줄 + 텍스트 2줄) · 메인 텍스트 최대 30자 |
| 편성 가능 영역 | B tv+ 홈 |
| 타겟팅 | 가능 |
| 최소 UI | **5.6.1 #2 이상** |

> ⚠️ 배너 규격 시트는 `5.6.1 #2 이상`, 다른 정책 문서는 `5.6.1 이상`으로 표기가 엇갈린다. 실무에서는 **5.6.1 #2 이상**을 기준으로 본다. 교차 검증이 필요하면 UI 배포팀에 확인한다.

## 장단점

| | |
| --- | --- |
| **장점** | B tv+ 홈 배너 중 **효율 최고**, 이미지 전면 노출 |
| **단점** | **B tv+ 월정액 가입자에게만** 노출 (다른 상품 가입자에게는 노출 안 됨) · UI 5.6.1 #2 이상만 가능해 **지원 UI가 전 배너 중 가장 높음** — 타겟 모수가 크게 줄어든다 |

## 일반 Today B tv와 구분

| | [Today B tv](MKI-B-02) | Today B tv+ |
| --- | --- | --- |
| 노출 대상 | B tv 전 고객(홈) | **B tv+ 가입자만**(B tv+ 홈) |
| 최소 UI | 5.4.1 이상 | **5.6.1 #2 이상** |
| 차지 비중 | 첫 화면 80%+ | 첫 화면 60%+ |

B tv+ 가입자 전용 혜택(리텐션·업셀)을 알릴 때 쓴다. B tv+ 미가입자까지 포함해 넓게 알리려면 일반 [Today B tv](MKI-B-02)나 [월정액 가입 빅배너](MKI-B-05)를 검토한다.
