> 적용대상 **공통** (PPM 전용 기능 표시)

## 이 문서는

**이 문서가 UI 버전 정보의 유일한 기준입니다.** 기능별 지원 UI 버전이 정책 문서마다 따로 적혀 있으면 한쪽만 갱신되고 나머지는 낡습니다. 정책 문서는 버전을 직접 적지 않고 이 표로 링크만 겁니다.

타겟 모수를 정하기 **전에** 이 표부터 보세요. "5.6.1 이상만 되는 기능"을 골랐다면, 그 순간 대상 고객이 크게 줄어듭니다 — 버전이 올라갈수록 대상 고객은 줄고 지원 기능은 늘어납니다.

## STB 종류 제약

- **HD 셋톱**: TV팝업 버튼이 보여도 랜딩 영역이 없어 **동작하지 않습니다**. 바로가기 버튼은 HD 셋톱 미지원입니다.

## 표기 규칙

- 원문의 542·543·551 같은 표기는 5.4.2·5.4.3·5.5.1로 옮겼습니다.
- 신규 UI 배포·기능 추가 시 이 표를 먼저 갱신하고, 정책 문서의 버전 인용을 맞춥니다.
