## STB 종류 제약

- **HD 셋톱**: TV팝업 버튼이 보여도 랜딩 영역이 없어 **동작하지 않는다**. 바로가기 버튼은 HD 셋톱 미지원.

## 표기 규칙

- 원문의 542·543·551 같은 표기는 5.4.2·5.4.3·5.5.1로 옮겼다.
- 신규 UI 배포·기능 추가 시 이 표를 먼저 갱신하고, 정책 문서의 버전 인용을 맞춘다.
