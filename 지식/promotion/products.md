> 적용대상 **공통** · 관련 시스템 CBS

## 이 문서는

프로모션이 다루는 상품 분류이자 **모든 기획의 첫 분기점**입니다. 트랙에 따라 적용되는 인사이트·카피 규칙·구좌 조합이 전부 달라집니다.

**왜 이렇게 갈리나** — 트랙별로 고객의 구매 심리와 규제 리스크가 완전히 다르기 때문입니다. 단건 구매(PPV)는 "이 작품을 볼까 말까"의 문제이고, 월정액(PPM)은 "매달 돈을 낼까 말까"의 문제입니다. **같은 카피 공식을 쓰면 둘 다 실패합니다.**

상품 유형별 정책은 [PPV(단건) 프로모션 정책](PPC-P-03) · [PPM(월정액) 프로모션 정책](PPC-P-02)을 따릅니다. 이 문서는 정책이 아니라 **기획 판단 기준**입니다.

## PPV — 단건 구매

| 항목 | 값 |
| --- | --- |
| 정의 | 콘텐츠 1편 단위 구매 (영화, 방송 다시보기 등) |
| 하위 구분 | 영화, 시리즈, 예능, 키즈 |
| 핵심 목표 | 구매 전환 (인지 → 시놉시스 진입 → 결제) |
| 대표 혜택 | 할인쿠폰 선발급, 쿠폰 다운로드, 구매자 경품 |
| 전용 카피 규칙 | [영화 PPV 카피 가이드](MKI-C-02) — **영화에만 적용** |

> 영화 전용 인사이트를 시리즈·예능·키즈·PPM·B tv+에 적용하지 않는다.

## PPM — 월정액

| 항목 | 값 |
| --- | --- |
| 정의 | 월 단위 구독 상품 (지상파·종편·CP별 월정액) |
| 핵심 목표 | 신규 가입 / 리텐션(해지방어) / 시청 유도 |
| 대표 혜택 | 첫달 100% 무료, 12개월 50% 할인, 다개월 정액 할인 |
| 규제 영향 | **다크패턴 규제 직접 적용** → [PPM(월정액) 프로모션 정책](PPC-P-02) |

## 갱신 기준

- 새 상품 트랙이 생기면 표에 행을 추가하고, 적용 문서 표에도 반영한다.
- 트랙별 세부 룰이 3개 이상 쌓이면 별도 문서로 분리하고 여기서는 링크만 남긴다.
- **개별 상품명은 여기 적지 않는다.** 캠페인마다 달라진다.

**아직 못 채운 것** — 시리즈·예능·키즈 PPV 전용 카피 인사이트는 아직 없습니다(현재는 영화만 정리). B tv+ 상품 구성(포함 채널·가격)의 최신 스냅샷도 없습니다.
