> 적용대상 **공통** · 관련 시스템 ACS · 규격은 [배너 규격](MKI-B-01) · 발송 Capa는 [배너·TV팝업·스마트알림 운영 기준](PPC-P-04)

## 이 문서는

배너에서 랜딩하거나 **TV를 켜자마자 단독 전면 노출**할 수 있는 팝업. 원하는 형태로 개발할 수 있어 기획 자유도가 가장 높다.

템플릿이 없는 프로모션, 또는 배너만으로 설명이 불가능한 복합 혜택을 안내할 때 쓴다.

**언제 쓰나**

- 특정 타겟에게 B tv를 켜자마자 **전면 강제 노출**하고 싶은 경우
- 배너에서 랜딩해 **추가 정보를 설명**하고 싶은 경우
- 템플릿이 없어 별도 개발이 필요한 프로모션

## 두 가지 유형

### 일반 TV팝업

기존 템플릿 사용. 개발이 필요 없다.

**지원 랜딩** — 시놉시스, 메뉴, 채널 바로가기, 구매창 바로가기, 모바일 B tv 페어링 등

### 개발 TV팝업

별도 개발. **약 2주 리드타임**이 필요하다.

**지원 랜딩** — 바로가기, 응모하기, 가입하기, 휴대폰번호 입력 후 문자 발송 등

## 리스크

| 리스크 | 내용 | 대응 |
| --- | --- | --- |
| **개발 기간** | 약 2주 소요 | 캠페인 일정에 반드시 반영. 촉박하면 일반 팝업이나 [풀페이지 배너](MKI-B-07)로 대체 |
| **하위 UI 미작동** | 개발 팝업은 구버전 UI에서 작동하지 않는 경우가 많아 **프로모션 타겟이 줄어든다** | 대상 셋탑의 UI 버전 분포를 먼저 확인 |

### 랜딩 기능별 UI 버전 제약

| 기능 | 제약 |
| --- | --- |
| 바로가기 | 5.1.3 이상. **단 HD 셋탑과 UI 5.2.0 미지원** |
| 응모하기 | **5.3.2 이상.** ⚠️ **HD 셋탑은 버튼이 노출돼도 동작하지 않는다**(랜딩 가능한 영역이 없음) |
| 가입하기 | **5.4.1 이상** |

> ### 🔴 응모하기를 쓰면 HD 셋탑을 모수에서 반드시 제외한다
>
> HD 셋탑에서는 응모하기 버튼이 화면에 보이지만 **눌러도 아무 일도 일어나지 않는다.** 고객은 버튼을 보고 누르는데 반응이 없으니 경품 프로모션에서는 **민원으로 직결**된다. 검토 사항이 아니라 필수 절차다.

## 규격

- 이미지 — Legacy/Smart **587×366**, UHD **1175×733**
- 버튼 — 최소 1개 ~ 최대 3개, 텍스트 **2~9자**(띄어쓰기 포함)

## 카피 방향

- 버튼 텍스트는 9자 제한이므로 **동사형 CTA**로 짧게 쓴다 (바로가기, 쿠폰받기, 응모하기)
- 팝업은 고객의 시청을 가로막는 형태이므로 **혜택을 첫 줄에** 배치한다
- 닫기 버튼 텍스트도 카피 대상이다. 기본값을 그대로 두지 않는다

## 권장 유저플로우

```
띠배너/빅배너 → TV팝업(안내) → 시놉시스 또는 가입창
TV팝업 (단독 강제 노출) → 가입창 또는 응모
```

## 기획 전 체크리스트

TV 팝업을 넣기로 했다면 순서대로 확인한다.

- [ ] 기존 템플릿으로 가능한가? → 안 되면 **개발 2주** 확보
- [ ] 이미지를 Legacy/Smart용과 UHD용 **두 종류** 준비했는가
- [ ] 버튼 텍스트가 **9자 이내**인가(띄어쓰기 포함)
- [ ] **응모하기 버튼을 쓰는가?** → 쓴다면 **HD 셋탑을 모수에서 제외**
- [ ] 가입하기 버튼을 쓰는가? → 쓴다면 **5.4.1 미만 제외**
- [ ] 팝업 자체 조건인 **5.3.2 미만**을 모수에서 제외했는가
- [ ] 쿠폰 프로모션인가? → [다크패턴 대응](PPC-P-02#h-다크패턴-대응-및-정가-전환동의) 기준 5.4.3 미만 포함 여부 검토
