> 적용대상 **PPM 전용** · 관련 시스템 CBS, ACS

## 이 문서는

월정액(PPM) 프로모션을 만들 때 **PPV와 다르게** 챙겨야 하는 제약만 모았습니다. PPV·PPM 공통 절차는 [프로모션 정책·업무 개요](PPC-P-01)에 있으니, 여기서는 PPM에만 걸리는 다섯 가지 챕터만 다룹니다.

**왜 PPM만 유독 까다로운가** — PPM은 쿠폰이 끝나면 **정가로 자동 전환**됩니다. 이 전환에 고객 동의를 받아야 한다는 규제('다크패턴' 법)가 걸려 있어서, 동의를 못 받으면 프로모션이 끝나는 순간 그 고객의 월정액이 **자동 해지**됩니다. 아래 다섯 챕터는 전부 이 전환동의 문제를 중심으로 얽혀 있습니다.

## 이 문서 안의 5개 챕터

| 챕터 | 언제 필요한가 |
| --- | --- |
| **다크패턴 대응 및 정가 전환동의** | 모든 PPM 쿠폰 설계에 기본으로 걸리는 규제. 가장 먼저 읽는다 |
| **30일 이하 월 운영 기준** | 캠페인이 2·4·6·9·11월에 걸치면 확인 |
| **약정상품(3/6/12개월) 쿠폰 정책** | 약정 월정액 대상 쿠폰을 만들 때 |
| **해지방어 쿠폰 운영** | 해지 시도 고객에게 쿠폰을 줄 때 |
| **PPM 쿠폰 스킴 설계 기준** | CBS에 쿠폰을 입력하기 직전, 전체 체크리스트 |

**PPM 마케팅**은 아직 채울 내용이 없습니다 — 원문 목차에 항목만 있고 본문이 없었습니다.

## PPM 관련 UI 버전 한눈에

다섯 챕터에 흩어진 버전 조건을 한 표로 모았습니다. 전체 표는 [UI 버전별 지원 현황표](PPC-R-01)에 있습니다.

| 기능 | 최소 UI 버전 |
| --- | --- |
| 약정상품 쿠폰 적용 | 5.3.5 (온스크린 노출은 5.4.1) |
| 월정액 가입 배너 타겟 편성 | 5.4.1 |
| 다크패턴 전환동의 팝업 | 5.4.3 |
| 30일 이하 월 가입 즉시 전환동의 팝업 | 5.5.2 |
| 일자별 쿠폰 생성 | 5.6.2 (2026년 11월 예정) |

## 다크패턴 대응 및 정가 전환동의

> 적용대상 **PPM 전용** · 관련 시스템 CBS

'다크패턴' 법 시행으로, 쿠폰을 사용해 월정액에 가입한 고객에게는 **정가 전환동의**를 받아야 합니다. 동의를 받지 못하면 **프로모션 적용 종료 시점에 해당 월정액이 자동 해지**됩니다.

| 항목 | 기준 |
| --- | --- |
| 전환 미동의 시 자동 해지 | **전체 UI**에 적용 |
| 전환동의 팝업 온스크린 노출 | **UI 5.4.3 이상**에만 적용 |
| 전환동의 요청 가능 시점 | 현행법상 전환 시점 **30일 이전**부터 |

**이 두 줄을 나란히 읽으면 문제가 보입니다.** 자동 해지는 전체 UI에 걸리는데, 동의 팝업은 5.4.3 이상에만 뜹니다. 즉 **UI 5.4.3 미만 고객은 동의할 화면 자체가 없는데도 자동 해지는 똑같이 적용됩니다.** 타겟 설계 시 UI 버전 분포를 반드시 확인하세요 — 모르고 포함하면 프로모션은 성공했는데 종료 후 남는 고객이 없는 결과가 나옵니다.

### CBS 설정 — 다크패턴 적용 제외여부

쿠폰 정책 생성 시 CBS의 **다크패턴 적용 제외여부** 값으로 동작이 결정됩니다.

| 설정 | 동작 |
| --- | --- |
| **N** (기본) | 쿠폰 적용 만료 30일 전부터 전환동의 팝업 발생. 미동의 시 자동 해지 |
| **Y** | 만료 전 전환동의 팝업이 뜨지 않음. 고객이 해지하지 않으면 유료로 자동 전환 |

- 해지방어 쿠폰과의 조합은 뒤의 **해지방어 쿠폰 운영** 참고
- 필드 상세: [CBS 쿠폰정책 핵심 필드·부가기능](PPC-CBS#h-쿠폰정책-핵심-필드·부가기능)

## 30일 이하 월 운영 기준

> 적용대상 **PPM 전용** · 관련 시스템 CBS

전환동의는 전환 시점 **30일 이전부터** 요청할 수 있습니다. 그런데 한 달이 30일보다 짧은 달(**2·4·6·9·11월**)에는 계산이 어긋납니다 — 고객이 쿠폰으로 가입하는 그 순간 이미 30일 이내로 들어가므로, **가입 즉시** 전환동의를 요청할 수 있습니다. 이 기능은 **UI 5.5.2 이상**에서 동작합니다.

### 적용 기간 산정

실제 프로모션은 **전월 말일 ~ 해당월 말일 -1일** 가입자에게 이 기능을 적용합니다.

| 운영 월 | 적용 가입 기간 |
| --- | --- |
| 9월 | 8월 31일 ~ 9월 29일 |

> 다른 달도 같은 규칙(전월 말일 ~ 해당월 말일 -1일)으로 계산합니다.

### 일자별 쿠폰 생성 기능 — 근본 해법은 개발 중

**지금은 모든 쿠폰이 '개월' 단위로만 생성**됩니다. 그래서 가입일 기준 같은 날짜에 정상가로 전환되고, 30일 이하 달마다 위와 같은 예외 계산이 필요합니다.

| 항목 | 내용 |
| --- | --- |
| 현재 | 모든 쿠폰은 빌링 시스템과 동일하게 **'개월' 단위**로만 생성 가능 → 가입일 기준 같은 날짜에 정상가 전환 |
| 개발 중 | 다크패턴 대응을 위해 **'일' 단위** 쿠폰 생성·적용 기능 개발 (예: 7일 이용 쿠폰, 15일 이용 쿠폰) |
| 대상 UI | **5.6.2 이상** (2026년 11월 예정) |
| 기대 효과 | 위 "가입 즉시 전환동의"와 연계하면, 일 단위 쿠폰 적용 시 **월별 일수와 관계없이 모든 달**에 즉시 전환동의 적용 가능 |

## 약정상품(3/6/12개월) 쿠폰 정책

> 적용대상 **PPM 전용** · 관련 시스템 CBS

약정 월정액(3·6·12개월) 할인 쿠폰은 **UI 5.3.5 이상** 고객에게만 적용되고, 온스크린에 약정 쿠폰 UI가 보이는 것은 **5.4.1 이상**입니다. 그래서 실무에서는 **5.4.1 이상 고객 대상으로만** 약정 쿠폰을 발급하고 있습니다.

| UI 버전 | 쿠폰 생성 | 고객 STB 적용 | 온스크린 약정 쿠폰 UI |
| --- | --- | --- | --- |
| 5.3.5 미만 | 가능 (버전 이슈 없음) | **미적용** | 미노출 |
| 5.3.5 ~ 5.4.1 미만 | 가능 | 적용 | **미노출** |
| 5.4.1 이상 | 가능 | 적용 | 노출 |

> 원문 표기는 "5.4.1 이하 온스크린 미지원"이나 같은 문단에서 "5.4.1 이상 고객 대상 발급"으로 운영 중이므로, 5.4.1부터 노출되는 것으로 정리했습니다. **확인 필요**: 5.4.1 포함 여부.

### CBS 적용대상 매핑 기준

CBS 쿠폰 적용대상에서 **매핑대상구분 = 약정**을 선택합니다.

- 월정액 쿠폰에서만 선택 가능
- 매핑한 약정(3/6/12개월) **외의 약정과 무약정 상품에는 적용 불가**
- 반대로 **무약정 쿠폰**을 발급한 경우에는 약정 상품 구매에도 사용 가능

상세: [CBS 쿠폰 적용대상 관리](PPC-CBS#h-쿠폰-적용대상-관리)

**스킴 수립 시 체크할 것** — 타겟 모수에서 5.4.1 미만 고객이 빠진다는 점을 반영해 목표를 잡으세요. 5.3.5 미만 고객에게 발급하면 쿠폰이 아예 적용되지 않아 VoC 원인이 될 수 있습니다.

## 해지방어 쿠폰 운영

> 적용대상 **PPM 전용** · 관련 시스템 CBS

할인 쿠폰으로 가입해 월정액을 이용 중인 고객에게 **해지방어 쿠폰**을 줄 때는 CBS의 **해지방어여부**를 설정합니다.

| 설정 | 동작 |
| --- | --- |
| **해지방어여부 Y** | 해지방어 쿠폰을 받은 고객의 **기존 쿠폰은 자동으로 전환동의한 것으로 처리** |
| **해지방어여부 Y + 다크패턴 적용 제외여부 Y** | 위 처리에 더해, **해지방어 쿠폰이 끝나는 시점에도 전환동의를 받지 않음** |

> 헷갈리기 쉬운 지점: 해지방어여부 Y만 체크해서는 **해지방어 쿠폰 자체**의 전환동의가 생략되지 않습니다. 해지방어 쿠폰 종료 시점에도 전환동의 팝업을 띄우지 않으려면 '다크패턴 적용 제외 여부' Y를 **추가로** 체크해야 합니다.

상세: [CBS 쿠폰정책 핵심 필드·부가기능](PPC-CBS#h-쿠폰정책-핵심-필드·부가기능)

## PPM 쿠폰 스킴 설계 기준

> 적용대상 **PPM 전용** · 관련 시스템 CBS, ACS
>
> **초안** — 원문 본문에 흩어진 PPM 설계 항목을 모은 문서입니다. 스킴 유형 정의는 첨부 "프로모션 스킴 생성 가이드 및 월정액 프로모션 운영 Map"을 기준으로 보완이 필요합니다.

CBS에 쿠폰을 입력하기 **직전** 마지막으로 훑는 체크리스트입니다. 위 다섯 챕터에서 나온 조건들이 여기 한 표에 다시 모여 있습니다.

| # | 항목 | 기준 | 근거 문서 |
| --- | --- | --- | --- |
| 1 | 할인율·유효기간 | 품의 내용과 동일하게 설계 | [운영 프로세스 Step 1](PPC-P-01#h-프로모션-운영-프로세스-(Step-1~6)) |
| 2 | 타겟 모수 | 품의 모수와 동일하게 확정. **UI 버전 조건을 먼저 걸고** 모수 산정 | [UI 버전표](PPC-R-01) |
| 3 | 최대발급수량 | 타겟 모수 기준으로 사전 설계. 초과 시 발급이 원천 차단됨 | [CBS 예외처리](PPC-CBS#h-예외처리·장애방지) |
| 4 | 중복발급 여부 | N: 동일 고객 1~4건 제한 / Y: 중복발급체크기간 기준 | [CBS 핵심 필드](PPC-CBS#h-쿠폰정책-핵심-필드·부가기능) |
| 5 | 적용 요금제 | **월단위 — PPM 쿠폰** | [상품 분류 체계](PPC-P-01#h-상품-분류-체계-(PPV-/-PPM)) |
| 6 | 매핑대상 | 상품(특정 월정액) 또는 약정(3/6/12개월) | [CBS 적용대상](PPC-CBS#h-쿠폰-적용대상-관리) |
| 7 | 전환동의 처리 | 다크패턴 적용 제외여부 N(기본) / Y 결정 | 위 **다크패턴 대응** |
| 8 | 해지방어 여부 | 해지방어 목적 쿠폰이면 해지방어여부 Y | 위 **해지방어 쿠폰** |
| 9 | 최대할인금액 | 정율 할인이면 제한여부·최대할인금액 설정 검토 (VAT 제외 기준) | [CBS 핵심 필드](PPC-CBS#h-쿠폰정책-핵심-필드·부가기능) |
| 10 | 약정 쿠폰 대상 | 5.4.1 이상 고객만 발급 | 위 **약정상품 쿠폰** |
| 11 | 운영 월 | 30일 이하 월이면 가입 즉시 전환동의 적용 기간 반영 | 위 **30일 이하 월** |
| 12 | 쿠폰명 | 이름 끝에 '쿠폰' 단어 금지 | [배너·TV팝업·스마트알림 운영 기준](PPC-R-06) |

**아직 못 채운 것** — 월정액 프로모션 스킴 유형 정의(예: 첫 달 할인, N개월 할인 등, 첨부 "프로모션 스킴 생성 가이드" 기준), 유효기간 설정방식(고정/유동)별 PPM 권장값(원문 CBS 필드 설명이 비어 있음).
