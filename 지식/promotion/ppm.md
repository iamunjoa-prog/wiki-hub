> 적용대상 **PPM 전용** · 관련 시스템 CBS, ACS

## 요약

월정액(PPM) 프로모션은 단건(PPV)과 달리 **정가 자동 전환**이 걸려 있어, 다크패턴 규제 대응이 가장 중요한 제약이다. 쿠폰으로 가입한 고객에게 정가 **전환동의**를 받지 못하면 프로모션 종료 시 월정액이 **자동 해지** 된다.

## 하위 문서

| 문서 | 핵심 한 줄 |
| --- | --- |
| **다크패턴 대응 및 정가 전환동의** | 전환동의 팝업은 UI 5.4.3 이상, 미동의 시 자동 해지는 전 UI 적용 |
| **30일 이하 월 운영 기준** | 2·4·6·9·11월은 가입 즉시 전환동의 요청 가능 (UI 5.5.2 이상) |
| **약정상품(3/6/12개월) 쿠폰 정책** | 적용은 5.3.5 이상, 실무는 온스크린 노출되는 5.4.1 이상 대상 발급 |
| **해지방어 쿠폰 운영** | 해지방어 쿠폰 수령 시 기존 쿠폰은 전환동의 처리됨 |
| **PPM 쿠폰 스킴 설계 기준** | 할인율·유효기간·모수·중복발급 설계 시 체크 항목 |
| **PPM 마케팅** | *(빈 페이지 — 내용 추가 예정)* |

## 다크패턴 대응 및 정가 전환동의

> 적용대상 **PPM 전용** · 관련 시스템 CBS

### 요약

'다크패턴' 법 시행으로, 쿠폰을 사용해 월정액에 가입한 고객에게는 **정가 전환동의**를 받아야 한다. 동의를 받지 못하면 **프로모션 적용 종료 시점에 해당 월정액이 자동 해지** 된다.

### 기준

| 항목 | 기준 |
| --- | --- |
| 전환 미동의 시 자동 해지 | **전체 UI** 에 적용 |
| 전환동의 팝업 온스크린 노출 | **UI 5.4.3 이상** 에만 적용 |
| 전환동의 요청 가능 시점 | 현행법상 전환 시점 **30일 이전** 부터 |

> UI 5.4.3 미만 고객은 팝업으로 동의를 받을 수 없지만 자동 해지는 똑같이 적용된다. 타겟 설계 시 UI 버전 분포를 반드시 확인한다.

### CBS 설정 — 다크패턴 적용 제외여부

쿠폰 정책 생성 시 CBS의 **다크패턴 적용 제외여부** 값으로 동작이 결정된다.

| 설정 | 동작 |
| --- | --- |
| **N** (기본) | 쿠폰 적용 만료 30일 전부터 전환동의 팝업 발생. 미동의 시 자동 해지 |
| **Y** | 만료 전 전환동의 팝업이 뜨지 않음. 고객이 해지하지 않으면 유료로 자동 전환 |

- 해지방어 쿠폰과의 조합은 **해지방어 쿠폰 운영** 참고
- 필드 상세: [CBS 쿠폰정책 핵심 필드·부가기능](PPC-CBS)

### 관련 기준

- 30일이 안 되는 달의 처리 → **30일 이하 월 운영 기준**
- '개월' 단위 쿠폰의 한계와 일자별 쿠폰 개발 계획 → **30일 이하 월 운영 기준**

## 30일 이하 월 운영 기준

> 적용대상 **PPM 전용** · 관련 시스템 CBS

### 요약

전환동의는 전환 시점 **30일 이전부터** 요청할 수 있다. 따라서 한 달이 30일 이하인 달(**2·4·6·9·11월**)에는 고객이 쿠폰으로 가입하는 **즉시** 전환동의를 요청할 수 있다. 이 기능은 **UI 5.5.2 이상** 에서 동작한다.

### 적용 기간 산정

실제 프로모션은 **전월 말일 ~ 해당월 말일 -1일** 가입자에게 이 기능을 적용한다.

| 운영 월 | 적용 가입 기간 |
| --- | --- |
| 9월 | 8월 31일 ~ 9월 29일 |

> 다른 달도 같은 규칙(전월 말일 ~ 해당월 말일 -1일)으로 계산한다.

### 일자별 쿠폰 생성 기능

| 항목 | 내용 |
| --- | --- |
| 현재 | 모든 쿠폰은 빌링 시스템과 동일하게 **'개월' 단위** 로만 생성 가능 → 가입일 기준 같은 날짜에 정상가 전환 |
| 개발 중 | 다크패턴 대응을 위해 **'일' 단위** 쿠폰 생성·적용 기능 개발 (예: 7일 이용 쿠폰, 15일 이용 쿠폰) |
| 대상 UI | **5.6.2 이상** (2026년 11월 예정) |
| 기대 효과 | '정상가 전환 30일 이하' 구매 즉시 전환동의 팝업과 연계하면, 일 단위 쿠폰 적용 시 **월별 일수와 관계없이 모든 달** 에 즉시 전환동의 적용 가능 |

## 약정상품(3/6/12개월) 쿠폰 정책

> 적용대상 **PPM 전용** · 관련 시스템 CBS

### 요약

약정 월정액(3·6·12개월) 할인 쿠폰은 **UI 5.3.5 이상** 고객에게만 적용되고, 온스크린에 약정 쿠폰 UI가 보이는 것은 **5.4.1 이상** 이다. 그래서 실무에서는 **5.4.1 이상 고객 대상으로만** 약정 쿠폰을 발급하고 있다.

### UI 버전별 동작

| UI 버전 | 쿠폰 생성 | 고객 STB 적용 | 온스크린 약정 쿠폰 UI |
| --- | --- | --- | --- |
| 5.3.5 미만 | 가능 (버전 이슈 없음) | **미적용** | 미노출 |
| 5.3.5 ~ 5.4.1 미만 | 가능 | 적용 | **미노출** |
| 5.4.1 이상 | 가능 | 적용 | 노출 |

> 원문 표기는 "5.4.1 이하 온스크린 미지원"이나 같은 문단에서 "5.4.1 이상 고객 대상 발급"으로 운영 중이므로, 5.4.1부터 노출되는 것으로 정리했다. *(보완 필요: 5.4.1 포함 여부 확인)*

### CBS 적용대상 매핑 기준

CBS 쿠폰 적용대상에서 **매핑대상구분 = 약정** 을 선택한다.

- 월정액 쿠폰에서만 선택 가능
- 매핑한 약정(3/6/12개월) **외의 약정과 무약정 상품에는 적용 불가**
- 반대로 **무약정 쿠폰** 을 발급한 경우에는 약정 상품 구매에도 사용 가능

상세: [CBS 쿠폰 적용대상 관리](PPC-CBS)

### 스킴 수립 시 체크

- 타겟 모수에서 5.4.1 미만 고객이 빠진다는 점을 반영해 목표를 잡는다.
- 5.3.5 미만 고객에게 발급하면 쿠폰이 적용되지 않아 VoC 원인이 될 수 있다.

## 해지방어 쿠폰 운영

> 적용대상 **PPM 전용** · 관련 시스템 CBS

### 요약

할인 쿠폰으로 가입해 월정액을 이용 중인 고객에게 **해지방어 쿠폰** 을 줄 때는 CBS의 **해지방어여부** 를 설정한다.

### CBS 설정

| 설정 | 동작 |
| --- | --- |
| **해지방어여부 Y** | 해지방어 쿠폰을 받은 고객의 **기존 쿠폰은 자동으로 전환동의한 것으로 처리** |
| **해지방어여부 Y + 다크패턴 적용 제외여부 Y** | 위 처리에 더해, **해지방어 쿠폰이 끝나는 시점에도 전환동의를 받지 않음** |

> 해지방어 쿠폰 종료 시점에 전환동의 팝업을 띄우지 않으려면 '다크패턴 적용 제외 여부' Y를 **추가로** 체크해야 한다. 해지방어여부 Y만으로는 해지방어 쿠폰 자체의 전환동의는 생략되지 않는다.
