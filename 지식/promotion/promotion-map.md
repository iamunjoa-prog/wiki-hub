## 이 페이지는

B tv 프로모션이 어떻게 나뉘는지 알려주는 지도입니다. **지금 맡은 건이 어떤 종류인지 여기서 확인하고, 해당 페이지로 이동하세요.**

처음이라면 5분만 읽고 넘어가도 됩니다. 나중에 다시 돌아와서 보게 됩니다.

## 1. 먼저, 상품 분류부터

B tv 프로모션은 **어떤 상품을 다루는지**에 따라 네 갈래로 나뉩니다. 이게 모든 것의 출발점입니다.

| 상품 분류 | 무엇인가 | 대표 상품 |
| --- | --- | --- |
| **PPM** (월정액) | VOD를 매달 정액으로 무제한 보는 구독 상품 | **B tv+**, 지상파 3사 월정액, JTBC 월정액, CJ ENM 월정액 |
| **PPV** (단건) | VOD를 한 편씩 사서 보는 상품 | 영화, 애니메이션, TV방송 |
| **실시간 채널** | 실시간으로 방송되는 유료 채널 | SPOTV Prime, 캐치온, DOG TV |
| **비과금** | 파는 게 아니라 알리기만 하는 건 | 에이닷 안내, B캐시 적립, 커머스 링크 |

> **PPM·PPV는 실무에서 상품을 구분하는 이름입니다.**
> 글자만 보면 과금 방식처럼 보이지만, 실제로는 상품 분류 체계로 씁니다.

### PPM과 PPV는 마케팅 방식이 다릅니다

이 둘을 갈라놓는 이유는 **고객을 움직이는 방법이 다르기 때문**입니다.

| | **PPM** | **PPV** |
| --- | --- | --- |
| 고객 행동 | 가입한다 → 계속 본다 | 하나 산다 → 본다 |
| 마케팅 목표 | 가입시키고 **오래 유지**시키기 | **한 건 더** 구매하게 하기 |
| 대표 혜택 | 12개월 50% 할인 등 **장기 할인** | 콘텐츠별 **할인 쿠폰** |
| 성패 기준 | 가입 후 얼마나 남아 있는가 | 지금 사게 만들었는가 |

PPM에서 "12개월 50% 할인" 같은 긴 혜택을 쓰는 건, 가입만 시키는 게 아니라 **혜택이 끝난 뒤에도 남게** 만들어야 하기 때문입니다. PPV는 반대로 그 순간의 구매 결정을 만드는 데 집중합니다.

### 실시간 채널은 PPM이 아닙니다

SPOTV Prime이나 캐치온도 돈을 내고 보지만, **PPM으로 분류하지 않습니다.** PPM은 VOD 월정액에만 쓰는 이름입니다. 실시간 채널은 PPM·PPV 같은 약어 없이 그대로 「실시간 채널」이라고 부릅니다.

### 예전 문서에서 마주칠 용어 두 개

| 옛 용어 | 지금은 |
| --- | --- |
| **PPC** | **사용하지 않습니다.** 문서마다 뜻이 달라(통칭/단건) 혼선이 있었습니다. PPM·PPV·실시간 채널로만 구분하세요. 단 `PPC사업팀`은 팀 이름이므로 그대로 쓰입니다 |
| **유료채널** | 「실시간 채널」로 바뀌었습니다 |

> 이 위키의 문서 코드(`PPC-P-01` 등)는 팀 이름 `PPC`에서 그대로 따온 식별자라 위 결정과 별개로 유지합니다. 본문에서 상품 분류를 가리킬 때만 `PPC`를 쓰지 않는다는 뜻입니다.

## 2. 프로모션을 구분하는 5가지 축

모든 프로모션은 아래 5개 항목으로 위치가 정해집니다. **이 다섯 개만 정하면 무엇을 만들어야 하는지가 결정됩니다.**

| 축 | 고르는 값 | 질문 |
| --- | --- | --- |
| **① 편성 대상** | B tv / 모바일 B tv | 어느 화면에 나가나? |
| **② 상품 분류** | PPM / PPV / 실시간 채널 / 비과금 | 무엇을 다루나? |
| **③ 목표** | 인지 / 구매(가입) / 리텐션 / 시청 / 해지방어 | 고객이 무엇을 하게 만들 건가? |
| **④ 유형** | 안내 / 할인 / 경품 / 할인+경품 | 무엇을 주나? |
| **⑤ 타겟** | 매스 / 타겟 | 전체에게? 특정 고객에게만? |

### 각 축 설명

**① 편성 대상** — TV 화면(B tv)인지 앱(모바일 B tv)인지. 만들 배너 규격이 달라집니다.
> 원본 시트에는 `편성 PoC 대상` / `POC`로 표기돼 있으나, 위키에서는 **「편성 대상」**으로 통일합니다.

**② 상품 분류** — 위 1번의 네 갈래. 이게 정해지면 볼 정책 페이지가 정해집니다.

**③ 목표** — 고객에게 기대하는 행동입니다.
- `인지` — 이런 게 있다는 걸 알리기
- `구매(가입)` — 사게/가입하게 하기
- `리텐션` — 이미 가입한 고객을 계속 쓰게 하기
- `시청` — 가입은 했는데 안 보는 고객을 보게 하기
- `해지방어` — 해지하려는 고객을 붙잡기

**④ 유형** — 고객에게 제공하는 혜택입니다.
- `안내` — 혜택 없이 알리기만
- `할인` — 쿠폰 제공
- `경품` — 응모/추첨 또는 전원 지급
- `할인+경품` — 둘 다

**⑤ 타겟** — `매스`는 모든 고객에게 노출, `타겟`은 조건에 맞는 고객에게만 노출. 타겟은 ACS에서 대상 고객을 추출하는 작업이 추가로 필요합니다.

## 3. 좌표를 정하면 나머지가 따라옵니다

5축을 정하면 **「이벤트 유형」 표**(구글시트 「2-2. [스펙] 이벤트 유형」)에서 해당하는 줄을 찾을 수 있고, 그 줄에 이런 것들이 이미 적혀 있습니다.

- **USER FLOW** — 고객이 배너를 보고 구매까지 가는 경로
- **할인 혜택 / 경품 혜택** — 실제로 쓸 수 있는 오퍼 종류
- **편성 기간** — 보통 며칠 운영하는지
- **주요 편성 영역** — 어느 화면의 어느 자리에 노출되는지
- **주요 제작 배너** — 디자인 요청해야 할 배너 목록

> 📎 이벤트 유형 표는 담당자에게 링크를 요청하세요 — 사내 구글시트라 이 위키(공개)에는 URL을 올리지 않습니다.

## 4. 읽는 법 — 실제 예시 3개

### 예시 1. B tv+ 주말 타임딜

| 축 | 값 |
| --- | --- |
| 편성 대상 | B tv |
| 상품 분류 | **PPM** — B tv+ |
| 목표 | 구매(가입) |
| 유형 | 할인 |
| 타겟 | 타겟 |

→ USER FLOW: `할인쿠폰 선발급 → 배너 → 월정액 가입창`
→ 혜택: 12개월 월 5,500원 청구
→ 기간: 4일 내 (목~일 또는 금~월)
→ 만들 것: [Today B tv 배너](MKI-B-02), [2단배너](MKI-B-03), 월정액 가입배너, [띠배너](MKI-B-06)

**왜 4일인가** — 짧게 운영해 "지금 아니면 안 된다"는 압박을 만드는 방식입니다. 할인율이 큰 오퍼는 길게 열지 않습니다.

### 예시 2. 최신 영화 할인 이벤트

| 축 | 값 |
| --- | --- |
| 편성 대상 | B tv |
| 상품 분류 | **PPV** — 영화 |
| 목표 | 구매(가입) |
| 유형 | 할인 |
| 타겟 | 매스 |

→ USER FLOW: `배너 → 콘텐츠 시놉시스 → 구매 → 할인쿠폰 자동 발급`
→ 혜택: 30% 할인 쿠폰 등 ⚠️ 세부 할인율은 CP 협의에 따라 다름
→ 기간: 14일
→ 만들 것: [Today B tv 배너](MKI-B-02), [롱배너](MKI-B-04), [2단배너](MKI-B-03), [빅배너](MKI-B-05)

### 예시 3. 월정액 해지방어 팝업

| 축 | 값 |
| --- | --- |
| 편성 대상 | B tv |
| 상품 분류 | **PPM** |
| 목표 | 해지방어 |
| 유형 | 할인 |
| 타겟 | 타겟 |

→ USER FLOW: `TV팝업 → 할인쿠폰 다운로드`
→ 혜택: 1개월 무료 / 1개월 70% / 2개월 50% / 1개월 100원 등
→ 기간: 상시
→ 만들 것: [TV팝업](MKI-B-09)
