## 이 문서는

배너·TV팝업·스마트알림을 **ACS에서 실제로 편성·발송할 때** 걸리는 운영 기준을 모았습니다. 구좌 자체의 스펙(글자수·이미지 규격)은 [배너 규격](MKI-B-01)에, 여기서는 **타겟팅·연동·발송 규칙**만 다룹니다.

| 챕터 | 무엇을 다루나 |
| --- | --- |
| **배너 유형별 편성 기준** | 타겟 한정 배너, 월정액 가입 배너, 시놉시스 배너의 버전·SEG ID 규칙 |
| **TV팝업 운영 기준** | 버튼별 지원 범위, ACS 연동 |
| **스마트알림 발송 규칙 및 네이밍 금칙** | 자동 발송 조건, 쿠폰명 작성 금칙 |

## 배너 유형별 편성 기준

> 적용대상 **공통** (월정액 가입 배너는 `[PPM]`) · 관련 시스템 ACS, EUXP, NCMS

### 타겟 고객 한정 배너

쿠폰 발급 고객이나 별도로 타겟 설정한 고객에게**만** 보이는 배너. **UI 5.3.2 이상** 에서 사용 가능하지만, 배너 유형마다 지원 UI가 다르므로 먼저 확인한다.

| 배너 유형 | 최소 UI 버전 |
| --- | --- |
| 풀 프로모션 블록 | 5.3.4 |
| 홈 Today B tv 배너, 띠배너 | 5.4.1 |
| Today B tv+ 배너 | 5.6.1 |

#### SEG ID 규칙

- 배너 유형과 관계없이 **같은 SEG ID로 묶이면 모든 배너가 해당 고객에게 동시 노출** 된다.
- 고객별로 배너 유형을 다르게 보여주려면 **SEG ID를 따로 생성** 해야 한다.

### 월정액 가입 배너 `[PPM]`

B tv+ 홈 등 월정액 홈 상단의 월정액 가입 배너를 타겟 고객에게만 노출하는 기능. **UI 5.4.1 이상**.

- 빅배너 편성 시 **월정액 상품을 매핑** 한다.
- 배너 편성 위치를 **MASS 배너보다 앞** 으로 설정한다.

### 시놉시스 배너 (EUXP 편성)

기능마다 지원 버전이 다르다.

| 기능 | 지원 범위 | 비고 |
| --- | --- | --- |
| 시놉시스 배너 편성 | 하위 버전 모두 호환 | |
| 단순 동작 | 5.3.X 이후 (NCMS 편성과 동일) | 5.3.3은 동작 확인됨 |
| 쿠폰 다운로드 | 5.4.2 이후 | 쿠폰 다운로드 기능 자체가 5.4.2에서 개발됨 — **모든 배너 동일** |
| Target 노출 | 타겟 기능이 동작하는 모든 STB | 서버 쪽 개발 |
| Today B tv 내 노출 | 5.4.3 이후 | |
| Target 노출 + Today B tv 노출 | 5.5.1 이상 | Today B tv가 SEG 정보를 참조하게 된 버전 |

> 원문은 542·543·551처럼 점 없이 표기되어 있어 5.4.2·5.4.3·5.5.1로 옮겼다.

## TV팝업 운영 기준

> 적용대상 **공통** · 관련 시스템 ACS

TV팝업은 **STB 종류와 UI 버전에 따라 쓸 수 있는 버튼이 다릅니다**. 팝업 기획 전에 버튼별 지원 범위를 확인하세요.

### 버튼별 지원 범위

| 버튼 | 지원 조건 | 주의 |
| --- | --- | --- |
| 바로가기 | UI 5.1.3 이상 | **HD 셋톱, UI 5.2.0 미지원** |
| 가입하기 | UI 5.4.1 이상 | |
| 응모하기 | UI 5.3.2 이상 | ⚠️ **HD 셋톱은 버튼이 노출돼도 동작하지 않음** — 응모형은 HD 셋톱을 모수에서 필수 제외 |

> **HD 셋톱**은 랜딩 가능한 영역이 없어, 버튼이 보이더라도 **실제로 동작하지 않습니다**.

### ACS 캠페인에서 TV팝업 쓰기

- ACS 채널 **TV 팝업 / OAP** 에서 상용 편성된 TV팝업 중 타겟팅할 팝업 ID를 매핑한다.
- 화면 하단 **메일 기안 UI** 로 편성 채널 담당자에게 연동 협조 메일을 즉시 상신한다.
- **피로도 정책**: 타겟팅 제외조건에서 **동일 캠페인 접촉 제외** 와 **TV팝업 2주 2회 제외** 를 체크해 민원을 예방한다.
- 상용 발송 전 본인 테스트 STB로 노출을 확인한다. → [ACS 테스트 STB 검증](PPC-ACS#h-P2-—-테스트-STB-검증-및-승인요청)

## 스마트알림 발송 규칙 및 네이밍 금칙

> 적용대상 **공통** (전체 UI) · 관련 시스템 CBS, ACS

쿠폰·B캐시·B포인트가 **발급되거나 만료될 때** 토스트 팝업 형태의 스마트알림이 **자동 발송**됩니다. 알림 문구가 고정되어 있으므로 **쿠폰·B캐시 이름 끝에 '쿠폰'/'B캐시'를 넣으면 안 됩니다.**

### 자동 발송 대상

쿠폰 발급 · B포인트 발급 · B캐시 발급 · 기간 만료 쿠폰 · 기간 만료 B포인트 · 기간 만료 B캐시

- 진입 시 알림 유형별 **우선순위에 따라 하나의 알림만** 보여준다.
- ACS 캠페인을 할 때는 **스마트알림 발송 일정을 함께 고려** 한다.

### 발송 규칙

| 알림 | 규칙 |
| --- | --- |
| **발급 알림** | 신규 발급이 여러 건이면 **묶어서 1회** (가장 최근 쿠폰명을 대표로 노출). 발급 후 **발급일+6일 23:50 이내 최초 1회**. 쿠폰함에 들어가면 쌓인 신규 알림은 모두 소멸 |
| **만료 알림** | 만료 **3일 전 1회**, **만료 전일** 전체 시간, **당일 23:50 이전** 중 1회 |

### 네이밍 금칙

알림 문구가 "OO 쿠폰/B캐시가 발급/만료됨" 형태로 고정되어 있다.

| 알림 | 고정 문구 |
| --- | --- |
| 발급 | [쿠폰명] 쿠폰이 도착했어요! |
| 만료 | [쿠폰명] 보유한 쿠폰은 YYYY년 MM월 DD일까지 사용할 수 있어요 |

| 구분 | 쿠폰명 | 실제 알림 |
| --- | --- | --- |
| 잘못된 예 | B tv+ 첫달 50% 할인쿠폰 | B tv+ 첫달 50% 할인쿠폰 쿠폰이 도착했어요! |
| 올바른 예 | B tv+ 첫달 50% 할인 | B tv+ 첫달 50% 할인 쿠폰이 도착했어요! |

### [쿠폰 사용하기] 버튼 노출 조건

CBS에서 **쿠폰 랜딩 설정**을 해야 쿠폰함과 스마트알림에 **[쿠폰 사용하기]** 버튼이 노출됩니다. 사용률에 영향을 주므로 필수로 설정하세요. → [CBS 정책 등록 4단계](PPC-CBS#h-P1-—-쿠폰·B캐쉬-정책-등록-및-승인요청)
