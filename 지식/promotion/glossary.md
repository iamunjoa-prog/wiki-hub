> 적용대상 **공통**

## 이 문서는

프로모션 업무에서 마주치는 약어·용어를 찾아보는 사전입니다. 처음부터 끝까지 읽는 문서가 아니라 **모르는 단어가 나왔을 때 Ctrl+F로 찾아 쓰는 문서**입니다.

용어 옆에 상태를 표시합니다.

- 표시 없음 — 원문에 정의가 있어 그대로 옮김
- **확인 필요** — 원문에 정의가 없거나 애매해서 아직 못 채운 용어

옛 용어 `PPC`·`유료채널`을 왜 더 안 쓰는지는 [프로모션 한눈에 보기](PPC-P-00)의 "예전 문서에서 마주칠 용어 두 개"를 참고하세요.

## 상품·과금

| 용어 | 설명 |
| --- | --- |
| **PPV** | VOD 단건 구매 상품. 쿠폰은 건 단위 → [상품 분류](PPC-P-01) |
| **PPM** | 월정액 상품. 쿠폰은 월 단위. 본 트리에서 "월정액" = PPM |
| **실시간 채널** | 실시간으로 방송되는 유료 채널(SPOTV Prime, 캐치온 등). **PPM이 아니다** — PPM·PPV와 나란한 별도 상품 분류로, 그대로 「실시간 채널」이라 부른다 → [프로모션 한눈에 보기](PPC-P-00) |
| **비과금** | 판매가 아니라 안내만 하는 프로모션(에이닷 안내, B캐시 적립, 커머스 링크 등) |
| **PPS** | CBS 상품 유형 선택지 중 하나 — **확인 필요** |
| **약정** | 3·6·12개월 약정 월정액 → [약정상품 쿠폰](PPC-P-02#h-약정상품(3/6/12개월)-쿠폰-정책) |
| **B캐쉬 / B캐시** | 쿠폰과 별도로 CBS에서 생성·발급하는 캐시. 판매용/판촉용 구분. (원문에 두 표기 혼용) |
| **B포인트** | CBS에서 생성 가능하나 **현재 실무 미사용** |

## 쿠폰 정책

| 용어 | 설명 |
| --- | --- |
| **정산제외 / 판매용 / 판촉용 쿠폰** | 품의 결재 기준이 달라지는 쿠폰 유형 → [결재 라인](PPC-R-02) |
| **할인권 / 이용권** | 쿠폰 종류. 이용권은 MOBILE 디바이스 전용 |
| **쿠폰정책 시작/종료일** | 고객이 쿠폰을 **등록(인증)**할 수 있는 기간 |
| **유효기간** | 등록 후 실제 **사용** 가능한 기간 — 쿠폰정책 시작/종료일과 헷갈리지 않도록 주의 |
| **적용대상 / 매핑대상구분** | 쿠폰을 쓸 수 있는 상품·컨텐츠 범위 → [CBS 적용대상](PPC-CBS#h-쿠폰-적용대상-관리) |
| **쿠폰 랜딩 설정** | 쿠폰함·스마트알림의 [쿠폰 사용하기] 버튼 노출 조건 |
| **쿠폰 추천순위** | 쿠폰함 노출 우선순위 (추천순위 > 만료임박순 > 할인율순) |
| **쿠폰 상태 코드** | 등록 / 인증(30) / 사용완료(40) — 인증·사용완료 건은 전체취소 불가 |
| **서비스관리번호** | 고객 식별 번호. 엑셀 발급·조회의 기준 키 |
