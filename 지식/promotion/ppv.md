> 적용대상 **PPV 전용** · 관련 시스템 CBS, ACS
>
> **초안** — 현재 원문은 PPM 중심입니다. PPV 정책은 시스템 설정 기준만 옮겨 두었고, 정책·스킴은 추가 정리가 필요합니다.

## 이 문서는

PPV(단건) 프로모션을 만들 때 챙겨야 하는 내용을 모았습니다. [PPM(월정액) 프로모션 정책](PPC-P-02)과 짝을 이루는 문서지만, **PPV는 PPM만큼 별도 규제가 없습니다** — 다크패턴·전환동의·약정 제약은 PPV에는 해당하지 않습니다.

**PPV를 가르는 건 딱 하나입니다.** 어떤 범위의 컨텐츠에 쿠폰을 적용할지(적용 범위)를 정하는 것이 PPM에는 없는, PPV만의 설계 포인트입니다. 쿠폰은 **건 단위(PPV 쿠폰)**로 만들고, 적용 범위를 컨텐츠·CP·카테고리·시리즈·메타유형 등 **컨텐츠 단위**로 좁힐 수 있습니다.

## PPV 쿠폰 스킴 설계 기준

> 적용대상 **PPV 전용** · 관련 시스템 CBS, ACS
>
> **초안** — 공통 설계 항목만 옮겨 두었습니다. PPV 스킴 유형·권장값은 추가가 필요합니다.

CBS에 쿠폰을 입력하기 **직전** 훑는 체크리스트입니다. [PPM 쿠폰 스킴 설계 기준](PPC-P-02#h-PPM-쿠폰-스킴-설계-기준)과 항목 구성은 비슷하지만, 5번 "적용 범위"가 PPV만의 항목입니다.

| # | 항목 | 기준 | 근거 문서 |
| --- | --- | --- | --- |
| 1 | 할인율·유효기간 | 품의 내용과 동일하게 설계 | [운영 프로세스 Step 1](PPC-P-01#h-프로모션-운영-프로세스-(Step-1~6)) |
| 2 | 타겟 모수 | 품의 모수와 동일. 활용할 홍보물의 UI 버전 조건 확인 | [UI 버전표](PPC-R-01) |
| 3 | 최대발급수량·중복발급 | 사전 설계 필수 | [CBS 핵심 필드](PPC-CBS#h-쿠폰정책-핵심-필드·부가기능) |

| 5 | 적용 범위 | 컨텐츠 / 전체 / CP / 카테고리 / 시리즈 / 메타유형 중 선택 | 아래 **PPV 컨텐츠 단위 매핑 기준** |

## PPV 컨텐츠 단위 매핑 기준

> 적용대상 **PPV 전용** · 관련 시스템 CBS

PPV 쿠폰은 CBS **쿠폰 적용대상 관리**에서 쿠폰이 쓰일 컨텐츠 범위를 좁힐 수 있습니다. 범위가 넓은 순서로 **전체 → 메타유형 → 카테고리 → CP → 시리즈 → 컨텐츠**입니다 — 신작 하나만 대상이면 '컨텐츠'를, 장르 전체가 대상이면 '메타유형'을 고르는 식입니다.

| 구분 | 적용 범위 | 예시 |
| --- | --- | --- |
| **전체** | 모든 PPV 컨텐츠 (PPM 상품에는 미적용) | — |
| **메타유형** | 특정 메타 유형 컨텐츠 | 영화, 드라마, 예능, 교양 |
| **카테고리** | 특정 카테고리에 매핑된 컨텐츠 | 한국영화, 해외영화, MBC, KBS, 애니메이션 |
| **CP** | 특정 '컨텐츠 계약처명'이 공급한 컨텐츠 | — |
| **시리즈** | 에피소드 상위 시리즈 단위 | '김부장' 선택 시 1~10회차 모두 적용 |
| **컨텐츠** | VOD 단건 컨텐츠 1개 단위 (단건 쿠폰만 가능) | — |

> CP·카테고리·시리즈·메타유형은 기능 추가로 새로 생긴 구분입니다.

**공통 제약 조건** — **가격대**: 쿠폰 사용 가능한 가격대 지정(미설정 시 금액 제한 없음). **요일·시간**: 특정 요일(월~일)·시간대 지정 가능(기본값 제한 없음). 적용대상은 **승인 완료 후에도 수정 가능**하며, 수정하면 **이미 발급된 쿠폰에도 바로 적용**됩니다.

**관련 문서** — 화면 조작 방법은 [CBS 쿠폰 적용대상 관리](PPC-CBS#h-쿠폰-적용대상-관리), 설계 체크리스트는 위 **PPV 쿠폰 스킴 설계 기준**을 보세요.

**아직 못 채운 것** — 구분별 사용 권장 상황 (예: 신작 프로모션은 컨텐츠, 제휴 CP 프로모션은 CP 등).
