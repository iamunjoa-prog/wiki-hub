## 요약

실시간 채널 시청 중에만 노출되는 3종 배너. 카피 영역이 매우 작고 **모두 타겟팅이 불가능**하다.

실시간 채널 이용자라는 특정 행동 맥락의 고객에게 도달하기 위한 구좌다.

**언제 쓰나**

- 실시간 채널 시청자를 타겟으로 하는 캠페인
- 특정 채널과 연관된 프로모션 (채널별 배너 차등 설정 가능)

## 3종 비교

| 배너 | 위치 | 텍스트 제한 | 랜딩 |
| --- | --- | --- | --- |
| 미니 EPG 배너 | 실시간 채널 하단 EPG 영역 | 최대 5자 | 시놉시스, TV팝업, 메뉴(1depth) |
| 편성표 배너 | 실시간 채널 편성표 진입 시 | 최대 2줄, 메인 13자 / 서브 20자 | 시놉시스, TV팝업, 메뉴(1depth) |
| WING UI 배너 | 실시간 시청 중 좌우 키 → WING UI 하단 | 최대 5자 | 시놉시스, TV팝업, 메뉴(1depth) |

셋 다 최소 UI 5.5.2 이상에서 동작한다.

## 카피 방향

- 텍스트 영역이 극히 작으므로 **CTA 버튼(예: 바로가기)** 을 넣는 것이 유리하다
- 타이틀 프로모션처럼 짧은 정보 전달에 적합하다
- 채널별로 배너를 다르게 설정할 수 있으므로, 채널 연관 프로모션에 활용한다

## 권장 유저플로우

```
미니 EPG / WING UI / 편성표 배너 → 시놉시스 또는 TV팝업
```
