> 적용대상 **공통** · 관련 시스템 ACS · 규격은 [배너 규격 및 특성](MKI-B-01)

## 요약

특정 콘텐츠의 **시놉시스(상세) 화면 안에 편성하는 배너**. 고객의 최종 구매 결정 직전에 노출된다.

시놉시스 화면은 **구매 버튼 바로 옆**이다. 여기서 조건·혜택·기한을 명확히 전달하면 전환율이 크게 오른다.

**언제 쓰나**

- 특정 타이틀과 연관된 이벤트를 하는 경우
- 구매 조건과 혜택을 최종 확인시켜야 하는 경우

## 특성

**장점**

1. 타이틀 연관 이벤트에 최적
2. **복수 타이틀에 동일한 시놉 배너를 편성할 수 있다**
3. 타이틀에 시놉 배너를 편성하면, Today B tv에 해당 타이틀이 노출될 때 **시놉 배너가 함께 노출된다** (MASS 편성 5.4.3 이상, TARGET 편성 5.5.1 이상)

**단점** — 영역이 작다. 최대 2줄, 8자 제한.

**랜딩 특이사항** — `쿠폰받기` 랜딩은 **UI 5.4.2 이상**에서만 동작한다. → [UI 버전별 기능 지원 현황표](PPC-R-01)

## 작성 기준

- 조건·혜택·기한을 **확인된 정보 범위에서** 명확하게 작성한다
- 할인쿠폰 / 포인트백 / 경품 / 자동 지급 / 후지급 등 **지급 방식을 구분**한다
- `100% 지급`, `전원 증정`, `즉시 지급`, `단독`은 **실제 조건이 확인된 경우에만** 쓴다
- **구매 조건과 감상·시청 완료 조건을 혼용하지 않는다**
- 담당자가 제공하지 않은 금액·날짜·지급 시점을 만들지 않는다
- 혜택 지급 시점이 미확정이면 확정 표현을 쓰지 않는다

## 작성 구조

세 가지 중 하나를 택한다.

- 구매 조건 + 혜택
- 구매 조건 + 혜택 + 기한
- 행동 유도 + 확인된 혜택

형식은 다음과 같다.

```
(구매 조건) 시 (혜택)
(확인된 혜택), (종료일)까지
지금 (구매 행동)하고 (확인된 혜택) 받기
```

괄호 안의 값은 **현재 캠페인에서 확정된 정보로 교체**한다. 템플릿 문자열을 그대로 쓰지 않는다.
