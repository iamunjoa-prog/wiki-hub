> 문서를 새로 넣거나 옮길 때의 형식 규약. 형식을 못 맞춰도 본문만 주면 정리해 드린다.

## 파일 하나 = 문서 하나

지식 문서는 저장소의 `지식/` 폴더에 마크다운 파일로 둔다. **폴더가 곧 메뉴** 다.

| 폴더 | 메뉴 | 문서 코드 접두 |
| --- | --- | --- |
| `지식/programming/` | 편성 | `PRG-*` |
| `지식/promotion/` | 프로모션 | `PPC-P-*` · `PPC-R-*` |
| `지식/system/` | 시스템 매뉴얼 | `PPC-ACS` · `PPC-CBS` · `PPC-SWG` |
| `지식/guide/` | 이용 안내 | `HUB-*` |

파일명은 영문 소문자 + 하이픈으로 짓는다. (`ppm.md`, `ui-versions.md`)

## 프론트매터

파일 맨 위에 `---` 로 감싼 메타 정보를 둔다.

```yaml
---
title: PPM(월정액) 프로모션 정책
code: PPC-P-02
category: promotion
version: 1
updatedBy: 홍*동
updatedAt: 2026-09-14
ownerId: ppc-team
scope: PPM
systems: [CBS, ACS]
parent: null
order: 20
status: 정리완료
source: "원문 위치"
---
```

| 항목 | 설명 |
| --- | --- |
| `title` | 사이드바·문서 상단에 보이는 제목 |
| `code` | 문서 식별자. 챗봇이 근거를 표시할 때, 문서끼리 링크할 때 쓴다 |
| `category` | `programming` / `promotion` / `system` / `guide` — 어느 메뉴에 들어갈지 |
| `scope` | `PPM 전용` / `PPV 전용` / `공통` — 챗봇이 상품 유형으로 근거를 거를 때 쓴다 |
| `systems` | 관련 시스템 (`[CBS, ACS]`) |
| `order` | 메뉴 안에서의 정렬 순서 (작을수록 위) |
| `status` | 아래 상태 표기 참고 |
| `source` | 원문이 어디에 있었는지 |

## 상태 표기

| 표기 | 의미 |
| --- | --- |
| **정리완료** | 원문 내용을 옮기고 구조화함 |
| **초안** | 원문에 일부만 있어 보완이 필요함. 본문에 `보완 필요` 로 표시 |
| **빈 페이지** | 항목만 있고 본문이 없어 자리만 만들어 둠 |

보완이 필요한 부분은 숨기지 말고 본문에 *(보완 필요)* 로 남긴다. 무엇이 비었는지 보이는 편이 낫다.

## 적용대상 표기

본문 첫 줄에 사람이 읽을 메타 줄을 둔다.

```markdown
> 적용대상 **PPM 전용** · 관련 시스템 CBS
```

## 문서끼리 링크하기

링크 주소에 **문서 코드** 를 적는다. 파일 경로가 아니다.

```markdown
[담당자·결재 라인](PPC-R-02)
```

같은 문서 안의 다른 섹션을 가리킬 때는 링크 대신 **굵은 글씨** 로 섹션 이름을 적는다.

## 본문 작성

- 표, 목록, 인용(`>`), 코드블록 모두 그대로 렌더링된다.
- 소제목은 `##` 과 `###` 만 쓴다. 이 두 단계가 문서 우측 목차에 잡힌다.
- 문서가 길어도 괜찮다. 관련 내용이 한 페이지에 모여 있는 편이 여러 페이지로 쪼개진 것보다 읽기 쉽다.

## 컨플루언스에서 옮기는 법

1. 문서 → `...` → **Export** → Markdown 으로 내보내기
2. 내보낸 파일을 해당 폴더에 넣기 — 마크다운 정리는 이쪽에서 처리한다
3. 마크다운 내보내기가 막혀 있으면 페이지 본문을 복사해 `.md` 로 저장해도 된다

## 사내 정보 주의

**저장소에 넣기 전에 외부 반출이 가능한 범위인지 확인한다.**

아래 항목은 그대로 넣지 않는다.

- 임직원 **실명**·연락처·이메일 → `홍*동` 처럼 가린다
- **부서명** → `미디어**팀` 처럼 가린다
- 사내 시스템 **URL**·조직 코드 → `(사내 Confluence 원문 · URL 생략)` 처럼 대체한다
- 제휴사명이 드러나는 **실제 캠페인명**

> 판단이 애매하면 가리는 쪽을 택한다. 한번 공개된 내용은 되돌리기 어렵다.
