## 이 문서는

사이드바 **시스템 바로가기** 화면에 시스템을 새로 추가하거나, 접속 주소를 넣는 방법을 정리한 안내입니다.

**한 줄 요약** — 시스템 바로가기는 화면에서 **추가**(시스템 등록)하거나 비어 있는 접속 주소를 **수정**(URL 입력)할 수 있습니다. 둘 다 **관리자 승인**을 거쳐야 모두에게 보입니다.

**왜 승인을 거치나** — 시스템 목록은 팀 전체가 함께 쓰는 공용 목록입니다. 아무나 바로 늘리거나 주소를 바꿀 수 있으면, 잘못된 주소가 섞였을 때 누구도 목록을 믿지 못하게 됩니다.

## 화면 둘러보기

- 사이드바의 **시스템 바로가기**를 누르면 시스템 카드가 **편성 관련** · **마케팅 관련**으로 나뉘어 보입니다.
- 카드를 누르면 그 시스템이 새 탭으로 열립니다. 카드에 **로컬 전용** / **클라우드 전용** 표시가 있으면 그 망에 연결된 PC에서만 열립니다.
- 카드의 **별표**를 누르면 메인 화면 **자주 사용하는 시스템**에 올라갑니다. 별표는 내 브라우저에만 저장되는 개인 설정이라 승인이 필요 없습니다.

## 새 시스템 추가하기

1. 시스템 바로가기 화면 오른쪽 위 **시스템 등록**을 누릅니다.
2. 칸을 채웁니다.

| 칸 | 적는 것 |
| --- | --- |
| 시스템명 | 시스템 이름 (필수) |
| URL | 접속 주소. `http://` 또는 `https://` 로 시작해야 합니다 (필수) |
| 설명 | 이 시스템으로 무엇을 하는지 한 줄 |
| 접속 망 | 로컬 전용 / 클라우드 전용 중 하나 |
| 구분 | 편성 관련 / 마케팅 관련 중 하나 |

3. **등록 요청**을 누르면 내 화면에 **승인 대기**로 보입니다. 바로 목록에 추가되지는 않습니다.
4. 관리자가 **승인 관리 › 시스템 등록** 탭에서 승인하면 공용 목록에 추가되어 모두에게 보입니다. 반려되면 **반려된 등록 요청**에 사유가 함께 표시되니, 고쳐서 다시 등록 요청하면 됩니다.

## 접속 주소가 비어 있는 시스템에 주소 넣기

주소를 아직 못 받은 시스템은 카드를 눌러도 열리지 않고, 카드 안에 **URL 입력** 버튼이 있습니다.

1. 카드의 **URL 입력**을 누르고 주소를 적은 뒤 **등록 요청**을 누릅니다.
2. 카드에 **접속 주소 승인 대기**가 뜹니다. 대기 중에는 같은 카드에 주소를 또 넣을 수 없습니다.
3. 관리자가 승인하면 그 카드가 링크로 바뀌어 모두에게 열립니다.

## 이미 있는 시스템을 고치거나 지우기 (준비 중)

이미 주소가 들어 있는 시스템의 **주소 바꾸기**, 시스템 **이름·설명 고치기**, 시스템 **삭제**는 아직 화면에서 할 수 없습니다(준비 중). 바꿀 내용과 이유를 적어 허브 관리자에게 요청하세요.

## 등록·승인 결과는 어디에 저장되나

사내 시스템 주소는 공개 저장소(허브 코드)에 두지 않습니다. 대신 **팀 공유 드라이브의 파일 하나**에 쌓고, 허브가 그 파일을 읽고 씁니다. 그래서 어디서 허브를 켰느냐에 따라 저장 여부가 다릅니다.

| 허브를 켠 곳 | 화면 표시 | 저장 |
| --- | --- | --- |
| 내 PC 허브 + 공유 드라이브 지정 | 표시 없음 | 팀 공유 드라이브 파일에 저장 → 같은 파일을 가리키는 팀원 모두가 함께 봄 |
| 내 PC 허브 + 공유 드라이브 미지정 | **이 PC에만 저장 중** | 내 PC에만 저장 → 팀원에게 안 보임 |
| 배포된 허브(웹 주소로 접속) | **저장되지 않는 화면** | 저장 안 됨 → 새로고침하면 사라짐 |

**공유 드라이브 지정하는 법** — 허브 폴더의 `.env.local` 파일에 `HUB_SYSTEMS_FILE=` 다음으로 팀 공유 드라이브의 시스템 목록 파일 경로를 적습니다. 경로는 팀 담당자에게 받으세요. 적은 뒤에는 허브를 껐다 다시 켜야 반영됩니다.

> 시스템 등록과 주소 입력은 **공유 드라이브를 지정한 내 PC 허브**에서 하세요. 배포된 허브에서 한 등록은 남지 않습니다.
