# 담당자 로그인 설정 (Microsoft 365)

허브는 계정을 따로 만들지 않습니다. 회사 Microsoft 365(Entra ID) 계정으로 로그인합니다.

- **실무자**: 사내 계정이 있으면 누구나 로그인할 수 있습니다. 가입 절차는 없습니다.
- **관리자**: Entra에서 `Hub.Admin` 역할을 받은 사람만 승인 관리에 들어갑니다.
- **이름·팀**: 이름은 계정 표시 이름, 팀은 Microsoft 365 프로필의 **부서**에서 가져옵니다.
- **문서 작성자**: "+ 새 문서" PR에 남는 작성자는 로그인 토큰에서 읽습니다. 화면에서 바꿀 수 없습니다.

아래 1~3단계는 회사 IT(Entra 관리자)에게 요청할 내용입니다.

## 1. 앱 등록

Entra 관리 센터 → **앱 등록** → **새 등록**

| 항목 | 값 |
|---|---|
| 이름 | 플랫폼 담당 지식 허브 |
| 지원되는 계정 유형 | **이 조직 디렉터리의 계정만** (단일 테넌트) |
| 리디렉션 URI | 플랫폼 **SPA(단일 페이지 애플리케이션)**, `https://wiki-hub-eosin.vercel.app` |

로컬에서 함께 시험하려면 SPA 리디렉션 URI에 `http://localhost:5173`도 추가합니다.

등록이 끝나면 **개요** 화면의 두 값을 받아 둡니다.

- 애플리케이션(클라이언트) ID → `VITE_ENTRA_CLIENT_ID`
- 디렉터리(테넌트) ID → `VITE_ENTRA_TENANT_ID`

## 2. 권한

**API 사용 권한**에 Microsoft Graph `User.Read`(위임)가 있는지 확인합니다. 새 앱에는 기본으로 들어 있습니다.
회사 정책상 사용자 동의가 막혀 있으면 **관리자 동의 허용**을 눌러 줍니다.

## 3. 관리자 역할

1. 앱 등록 → **앱 역할** → **앱 역할 만들기**
   - 표시 이름: 허브 관리자
   - 허용되는 멤버 유형: 사용자/그룹
   - 값: `Hub.Admin` (정확히 이 값이어야 합니다)
2. **엔터프라이즈 애플리케이션** → 이 앱 → **사용자 및 그룹** → 관리자를 맡을 사람에게 `허브 관리자` 역할을 배정합니다.

허브 운영자가 직접 관리자를 바꾸고 싶다면, IT에 이 앱의 **소유자**로 지정해 달라고 요청하세요.
소유자가 되면 IT를 거치지 않고 역할을 배정할 수 있습니다.

로그인할 수 있는 사람을 특정 인원으로 좁히려면, 엔터프라이즈 애플리케이션 → 속성에서 **할당 필요**를 **예**로 바꿉니다.
그러면 사용자 및 그룹에 추가된 사람(또는 그룹)만 로그인할 수 있습니다.

## 4. Vercel 설정

Vercel 프로젝트 → Settings → Environment Variables에 두 값을 넣고 **다시 배포**합니다.

```
VITE_ENTRA_CLIENT_ID=<애플리케이션(클라이언트) ID>
VITE_ENTRA_TENANT_ID=<디렉터리(테넌트) ID>
```

화면은 빌드할 때 이 값을 읽으므로, 값을 넣은 뒤 반드시 새로 배포해야 합니다.
API도 같은 값으로 토큰을 검증합니다.
두 값이 비어 있으면 지금처럼 로그인 없이 데모 계정(김OO)으로 동작합니다.

## 알아 둘 점

- 수정 제안, 승인, 시스템 요청 기록은 아직 브라우저 메모리에만 있습니다. 로그인한 사람은 구분되지만, 이 기록을 담당자끼리 함께 보려면 공용 저장소(DB)가 별도로 필요합니다.
- 로컬 허브(`start-hub.bat`)는 내 PC에서만 열리므로 API 토큰 검증을 하지 않습니다.
