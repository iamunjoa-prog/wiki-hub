### 0-2. 기록 파일 위치 (문구에 넣는 값)

| OS | 화면에 보이는 경로 (실제 값으로 펼쳐서 출력) | `읽어주세요.txt` 표기 |
| --- | --- | --- |
| Windows | `C:\Users\<사용자이름>\wiki-hub-기록\설치기록.txt` (`%USERPROFILE%\wiki-hub-기록\설치기록.txt`) | `C:\Users\(내 이름)\wiki-hub-기록\설치기록.txt` |
| Mac | `/Users/<사용자이름>/wiki-hub-기록/설치기록.txt` (`~/wiki-hub-기록/설치기록.txt`) | `내 홈 폴더 > wiki-hub-기록 > 설치기록.txt` |

- 폴더 이름은 숨김 폴더(AppData·Library)를 피해 사용자가 직접 찾을 수 있게 한다.
- 파일은 하나다. 실행할 때마다 아래에 이어 쓴다(AC-8). 비밀번호·토큰은 남기지 않는다.
- 아래 표의 `{기록}` 은 이 경로를 실제 값으로 펼친 문자열이다.

## 4. 검은 창·터미널 창에 보이는 모든 줄 (반영: dev-server)

### 4-0. 출력 규칙

- 창에는 이 표의 줄만 나온다. winget·msiexec·npm·brew·claude·codex·vite·PowerShell 진행 표시줄은 모두 `{기록}` 으로만 보낸다(AC-3).
- 단계 번호 `[n/N]` 의 N은 이번 실행에서 실제로 할 단계 수다. 계정을 고른 경우 5단계, "모르겠어요"는 3단계(1·2·5만).
  - 1 허브 실행 준비물 설치 (Node.js 휴대용)
  - 2 허브 프로그램 파일 준비 (npm install)
  - 3 챗봇 연결 프로그램 설치 (claude / codex)
  - 4 내 계정 로그인
  - 5 바탕화면 아이콘 만들기
  - 순서는 dev-server가 바꿔도 된다. 문구 ID는 순서와 무관하다. 다만 4(로그인)는 사람이 손을 대는 유일한 단계이므로 끝 쪽에 둔다.

## 5. `읽어주세요.txt` 전문 — `server/hubZipRoot.ts` `readmeText` (반영: dev-server)

UTF-8 BOM + CRLF는 지금처럼 유지한다. `{받은 날짜}` `{버전}` 만 바뀌는 값이다.

```
플랫폼 담당 지식 허브 — 내 PC에서 쓰기

할 일은 세 가지뿐이에요.
  1. 압축 풀기
  2. start-hub 더블클릭 (보안 경고가 뜨면 아래대로 통과)
  3. 브라우저가 열리면 내 계정으로 로그인
그 밖에는 창이 알아서 합니다. 키보드는 누르지 않아도 돼요.


■ Windows

  1. 받은 wiki-hub.zip 을 우클릭 → [모두 압축 풀기] → [압축 풀기]
     이 글이 압축 파일 안에서 열려 있다면, 이 창을 닫고 압축부터 풀어 주세요.
  2. 풀린 wiki-hub 폴더에서 톱니바퀴 그림이 있는 start-hub 를 더블클릭
  3. 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
     "보안 경고" 창이 뜨면 [실행]
  4. 검은 창이 혼자 준비합니다. 처음에는 5~10분쯤 걸려요.
     브라우저에 로그인 화면이 뜨면 고른 계정으로 로그인하세요.
  5. 허브가 브라우저에 열리면 끝입니다.
     검은 창은 닫지 말고 최소화해 두세요. 닫으면 허브가 꺼집니다.


■ Mac

  1. 받은 wiki-hub.zip 을 더블클릭해 압축을 풀어요. (Safari로 받았다면 이미 풀려 있어요)
  2. 풀린 wiki-hub 폴더에서 start-hub.command 를
     우클릭(또는 control+클릭) → [열기] → 다시 뜨는 창에서 [열기]
  3. [열기] 없이 [완료]만 보이면:
     [완료] → 화면 왼쪽 위 Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안
     → 아래로 내려 "start-hub.command" 옆 [그래도 열기]
     → 다시 뜨는 창에서 [그래도 열기] → Mac 암호 입력
     [휴지통으로 이동]은 누르지 마세요.
  4. "터미널이 … 폴더에 접근하려고 합니다" 창이 뜨면 [허용]
  5. 터미널 창이 혼자 준비합니다. 처음에는 5~10분쯤 걸려요.
     브라우저에 로그인 화면이 뜨면 고른 계정으로 로그인하세요.
  6. 허브가 브라우저에 열리면 끝입니다.
     터미널 창은 닫지 말고 노란 단추로 내려 두세요. 닫으면 허브가 꺼집니다.
```
