# 챗봇 답변 엔진 안내 문구 (26.11.13 확정)

로그인 화면·대시보드·위키 문서에 같은 내용을 쓴다. 화면에서는 "CLI"라는 말을 쓰지 않고 **내 AI 계정 / 공용 AI 엔진** 으로 부른다. "Gemini"는 대비 표의 괄호 안에만 쓴다.

## 근거 (코드 기준)

| 항목 | 내 AI 계정 (Claude·ChatGPT CLI) | 공용 AI 엔진 (Gemini API) |
| --- | --- | --- |
| 쓰는 곳 | 내 PC용 허브에서만 (`server/cliBridge.ts`) | 웹 주소 허브(`api/`), 내 PC 허브에서 계정이 없을 때 |
| 질문 답변 | Claude: Read·Grep·Glob으로 문서를 찾아 읽음 / ChatGPT: 위키 전체를 넣고 기본 추론 | 위키 전체를 넣고 thinking LOW |
| AI로 수정 | 됨. Claude는 관련 문서도 Grep·Read로 참고 / ChatGPT는 고칠 문서만 | 됨. 고칠 문서만 봄 (`editGemini`) |
| 사용량 | 본인 유료 구독 | 공용 키 하나. 혼잡하면 예비 모델로 전환 |
| Jira 스케줄 확인 | Claude 계정만 | 안 됨 |
| 응답 시간 | 질문 최대 2~3분, 수정 최대 4~5분 | 대체로 빠름 |

내 PC용 허브 ZIP은 계정 기능이 켜진 배포에서 **로그인한 사람만** 받는다 (`api/download-hub.ts`). 그래서 로그인 화면에서는 받는 곳만 알려 준다.

## ① 로그인 화면 — 로그인 상자 아래, 접힌 안내

제목(항상 보임): **챗봇은 어떤 AI로 답하나요?**

펼친 본문:

> 허브 챗봇은 위키 문서를 근거로 답해요. 답하는 AI는 두 가지 중 하나예요.
>
> - **내 AI 계정** — Claude나 ChatGPT를 유료로 쓰고 있다면 내 PC용 허브를 설치해서 쓰세요. 문서를 더 꼼꼼히 읽고 답하고, Jira 스케줄 확인도 돼요.
> - **공용 AI 엔진** — 계정이 없으면 여기서 로그인해 바로 쓰면 돼요. 설치할 건 없어요.
>
> 내 PC용 허브는 로그인한 뒤 대시보드의 **⚙ 연결 설정**에서 받을 수 있어요.

## ② 내 AI 계정으로 쓰면 좋은 점

> - **더 정확해요** — 시간을 들여 문서를 꼼꼼히 읽고 답해요. Claude 계정은 질문에 맞는 문서를 직접 찾아 읽어요. 조건이 여러 개 엮인 기획 상담에 강해요.
> - **문서 수정도 꼼꼼해요** — 수정 제안의 **AI로 수정**도 내 계정으로 돌아요. Claude 계정은 고칠 때 관련된 다른 문서도 찾아보고 맞춰 고쳐요.
> - **붐벼도 괜찮아요** — 내 구독으로 돌아서 다른 사람 사용량 때문에 느려지거나 막히지 않아요.
> - **할 수 있는 일이 더 많아요** — Jira 스케줄 확인은 내 Claude 계정으로만 돼요.
> - 처음 한 번만 설치하면(5~10분) 그다음엔 바탕화면 아이콘으로 켜면 돼요.

## ③ 공용 AI 엔진(Gemini)과 다른 점

| | 내 AI 계정 | 공용 AI 엔진 (Gemini) |
| --- | --- | --- |
| 준비 | 내 PC에 한 번 설치 | 없음, 바로 사용 |
| 답의 깊이 | 문서를 꼼꼼히 읽음 | 전체를 훑어 빠르게 찾음. 간단한 질문에 맞음 |
| AI로 문서 수정 | 됨 · Claude는 관련 문서도 참고 | 됨 · 고칠 문서만 봄 |
| 붐빌 때 | 영향 없음 | 느려지거나 보조 AI로 바뀔 수 있음 |
| Jira 스케줄 확인 | 됨 (Claude) | 안 됨 |
| 응답 시간 | 조금 더 걸릴 수 있음 | 대체로 빠름 |
| 비용 | 내 구독에 포함 | 회사 공용 |

> 간단히 찾아보는 질문은 공용 엔진으로도 충분해요. 편성 기획처럼 여러 조건을 따져야 하거나 문서를 고칠 때는 내 AI 계정을 권해요.
