# 챗봇 → 프로모션 자동화 핸드오프 매핑 (초안)

> 작성: 지식 허브 담당 · 협의 대상: 프로모션 자동화 어드민 담당(심OO M)
> 상태: **초안 — 아래 "결정이 필요한 것" 3건을 확정하면 확정본이 된다**

## 이 문서가 정하는 것

챗봇이 대화로 정리한 프로모션 조건을 프로모션 자동화 화면으로 넘길 때,
**어떤 값을 어떤 이름으로 넘기고, 무엇은 넘기지 않는가.**

## 전제 — 필드 이름은 캠페인 신청 시트를 정본으로 삼는다

현재 필드 이름이 세 벌 돌아다닌다. 챗봇 내부 이름, 어드민 화면 이름, 캠페인 신청 시트 컬럼.
이 중 **이미 운영 중이고 지라 일감·시트 동기화가 올라타 있는 것은 캠페인 신청 시트** 하나뿐이다.
새 스키마를 만들지 말고 시트 컬럼을 공통 언어로 쓰는 것을 제안한다.

## 매핑 초안

| 시트 컬럼 (정본) | 챗봇이 보냄 | 값의 형태 | 비고 |
| --- | --- | --- | --- |
| 캠페인명 | O | 자유 문자열 | 담당자가 따옴표로 말했거나 "이벤트명은 ~"으로 말한 경우만. 아니면 **빈 값** |
| 시작일 | O | `YYYY-MM-DD` | |
| 종료일 | O | `YYYY-MM-DD` | |
| 채널 | O | `타겟배너` \| `TV팝업` \| `스마트알림` \| `토스트팝업` | 이 4개로 고정 |
| 구분 | O | `PPM(월정액)` \| `PPV(단건)` | 넘기기 직전 확인 질문으로 반드시 받는다 |
| 타겟 | O | 자유 문자열 (예: 최근 3개월 영화 구매 이력) | 모수 숫자가 아니라 **조건 서술** |
| 쿠폰 | △ | `할인쿠폰 선발급` \| `구매자 경품` \| `쿠폰 + 경품` | **결정 필요 1** — 시트는 Y/N 표기, 챗봇은 스킴 라벨 |
| 타겟수 | X | — | 어드민에서 입력 |
| 부서 | X | — | 어드민 로그인 정보 |
| 담당자 | X | — | 어드민 로그인 정보 |
| 실행시각 | X | — | 어드민에서 입력 |
| (대응 컬럼 없음) | △ | 근거 정책 문서 코드 (예: `PPC-P-02`) | **결정 필요 2** — 비고 컬럼에 실을지, 버릴지 |

**빈 값 원칙 — 대화에서 확인하지 못한 항목은 지어내지 않고 빈 값으로 보낸다.**
어드민에서 잘못 들어온 값을 지우는 것이 빈칸을 채우는 것보다 번거롭다.

## 챗봇이 넘기지 않는 것 (의도적)

- **카피·문구** — 트랙1의 템플릿 베리에이션 기능이 담당한다. 챗봇이 문구까지 밀어넣으면
  AI 문구 오류가 그대로 어드민 일감으로 흘러간다.
- **성과 예측치·모수 산정** — 문서에 근거가 없는 수치는 생성하지 않는다.
- **이미지·소재** — 챗봇 범위 밖.

## 결정이 필요한 것

**1. 쿠폰/스킴 표기.** 챗봇은 스킴 라벨(`할인쿠폰 선발급` 등), 시트는 쿠폰 유무 표기.
   어느 쪽에 맞출지, 혹은 스킴을 받을 컬럼을 하나 둘지.

**2. 근거 정책 코드를 넘길지.** 챗봇은 답변 근거가 된 정책 문서 코드를 갖고 있다.
   일감에 같이 남기면 나중에 "왜 이 조건인가"를 추적할 수 있다. 실을 곳이 필요하다.

**3. 전달 방식 — 이번 회의의 핵심.** 현재 외부 페이지는 URL 파라미터를 읽지 않아
   지금 연결하면 빈 화면이 열린다. 아래 중 택일이 필요하다.

   | 안 | 내용 | 비용 | 비고 |
   | --- | --- | --- | --- |
   | (a) | 어드민이 URL 쿼리 파라미터를 읽어 폼에 채운다 | 어드민 측 소규모 수정 | 가장 빠름 |
   | (b) | 챗봇이 시트에 임시저장 행을 쓰고 어드민이 불러간다 | 중간 | 시트 동기화 로직과 자연스럽게 붙음 |
   | (c) | 연결하지 않고 허브의 확정 카드에서 복사 → 어드민 붙여넣기 | 없음 | 수기 입력이 남아 상용화 목표에 미달 |
